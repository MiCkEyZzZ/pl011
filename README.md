# ARM PrimeCell UART (PL011) — техническое руководство

Русскоязычная книга об универсальном асинхронном приёмопередатчике
**ARM PrimeCell PL011**, собранная на [mdBook](https://rust-lang.github.io/mdBook/).

Структура и технические данные соответствуют официальному руководству ARM
**DDI 0183F** (PrimeCell UART (PL011) Technical Reference Manual, ревизия
r1p4). Это самостоятельный текст, а не официальный перевод ARM.

## Содержание

| Раздел | О чём |
|--------|-------|
| Предисловие | Назначение, аудитория, соглашения, литература |
| Глава 1 | Общее описание, возможности, параметры, отличия от 16C550 |
| Глава 2 | Функциональное описание: блоки, IrDA SIR, работа, модем, DMA |
| Глава 3 | Модель программиста: карта и описание регистров, прерывания |
| Глава 4 | Тестовая модель: обвязка, scan, тестовые регистры |
| Приложение A | Описание сигналов: APB, внутрикристальные, выводы |
| Приложение Б | Глоссарий |

## Сборка

```console
$ cargo install mdbook      # если ещё не установлен
$ mdbook serve --open       # предпросмотр на http://localhost:3000
$ mdbook build              # готовый сайт в ./book
```

```

├── book.toml          # конфигурация mdBook

│   ├── SUMMARY.md     # оглавление
│   └── ...
```

Собранный сайт (`book/`) в репозиторий не попадает — он создаётся командой
`mdbook build`.

## Источники

- ARM DDI 0183F, PrimeCell UART (PL011) Technical Reference Manual.
- Драйвер `drivers/tty/serial/amba-pl011.c` ядра Linux.
- Модель `hw/char/pl011.c` эмулятора QEMU.

## Лицензия и правовая оговорка

Текст книги написан самостоятельно и описывает технические факты устройства.
Документ ARM DDI 0183F является собственностью ARM Limited; его дословный
перевод или воспроизведение здесь не приводится.
