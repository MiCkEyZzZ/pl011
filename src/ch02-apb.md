# 2.2.1. Интерфейс AMBA APB

Контроллер подключён к шине AMBA APB как ведомое устройство. Обмен всегда
инициирует ведущий — обычно мост APB.

## Сигналы обмена

| Сигнал | Направление | Назначение |
|--------|-------------|------------|
| `PCLK` | вход | Тактовый сигнал шины |
| `PRESETn` | вход | Сброс шины, активен низким уровнем |
| `PSEL` | вход | Выбор устройства |
| `PENABLE` | вход | Разрешение передачи |
| `PWRITE` | вход | 1 — запись, 0 — чтение |
| `PADDR[11:2]` | вход | Адрес слова внутри блока |
| `PWDATA[31:0]` | вход | Данные для записи |
| `PRDATA[31:0]` | выход | Данные при чтении |

Регистры контроллера занимают область 4 КБ. Адрес передаётся битами
`PADDR[11:2]`: младшие два бита отбрасываются, поскольку все регистры
выровнены по границе 32-битного слова.

## Цикл записи

Активная фаза передачи начинается, когда ведущий одновременно выставляет
`PSEL` и `PENABLE` при `PWRITE = 1`. По фронту `PCLK` контроллер принимает
`PWDATA` и адрес и выполняет запись.

```text
            ┌──┐  ┌──┐  ┌──┐  ┌──┐
PCLK     ───┘  └──┘  └──┘  └──┘  └───
         ┌──────────────────────────┐
PSEL     ┘                          └──
         ┌──────────────────────────┐
PENABLE  ┘                          └──
         ┌──────────────────────────┐
PWRITE   ┘                          └──
         ┌──────────────────────────┐
PADDR    ┘      адрес регистра      └──
         ┌──────────────────────────┐
PWDATA   ┘      данные для записи   └──
                    ▲
                    └── запись происходит здесь
```

## Цикл чтения

При чтении (`PWRITE = 0`) контроллер выставляет значение регистра
на `PRDATA`. Данные действительны в конце активной фазы передачи
и снимаются после деактивации `PENABLE` или `PSEL`.

```text
            ┌──┐  ┌──┐  ┌──┐  ┌──┐
PCLK     ───┘  └──┘  └──┘  └──┘  └───
         ┌──────────────────────────┐
PSEL     ┘                          └──
         ┌──────────────────────────┐
PENABLE  ┘                          └──
         ┌──────────────────────────┐
PRDATA   ─────────┤ значение ├──────
                          ▲
                          └── данные действительны здесь
```

## Особенности

- Все обращения выполняются 32-битными словами.
- Запись в регистр только для чтения игнорируется.
- Чтение регистра `UARTDR` извлекает символ из принимающего FIFO —
  это не обычное чтение ячейки памяти, а операция над очередью.
- Чтение `UARTICR` не имеет смысла: регистр только для записи.
- Адреса внутри 4-КБ области, не занятые регистрами, зарезервированы.

## Замечание о 4-КБ области

Регистры идентификации расположены по адресам `0xFE0`–`0xFFC`, поэтому
блок занимает практически всю 4-КБ страницу. При построении карты памяти
системы это нужно учитывать: соседние устройства не должны попадать
в тот же диапазон.
