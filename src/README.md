# PrimeCell UART (PL011)

## Техническое руководство

PL011 — универсальный асинхронный приёмопередатчик (UART) семейства
ARM PrimeCell. Он обеспечивает последовательный обмен данными по линиям
TXD/RXD, поддерживает модемные сигналы, аппаратное управление потоком,
IrDA SIR и прямой доступ к памяти (DMA).

Эта книга — русскоязычное описание устройства, составленное по структуре
официального руководства ARM **DDI 0183F** (PrimeCell UART (PL011) Technical
Reference Manual, ревизия r1p4). Она не является официальным переводом ARM
и не заменяет оригинальную документацию.

### Базовые сведения

| Параметр | Значение |
|----------|----------|
| Семейство | ARM PrimeCell |
| Шина | AMBA APB, ведомое устройство |
| Разрядность регистров | 32 бита |
| Глубина FIFO | 16 символов (передача и приём) |
| Скорость передачи | программируемая, делитель 16 бит + 6 бит дроби |
| Формат кадра | 5–8 бит данных, контроль чётности, 1 или 2 стоп-бита |
| Дополнительно | IrDA SIR, DMA, модемные сигналы, аппаратное управление потоком |

Смещения регистров указаны относительно базового адреса блока, который
назначается при интеграции контроллера в систему на кристалле.
