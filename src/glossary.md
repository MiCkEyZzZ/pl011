# Приложение Б. Глоссарий

**AMBA** — Advanced Microcontroller Bus Architecture, семейство шин
ARM. Контроллер PL011 подключается по шине APB.

**APB** — Advanced Peripheral Bus, упрощённая шина AMBA для
периферийных устройств. Обращения выполняются за два такта.

**ATPG** — Automatic Test Pattern Generation, автоматическая
генерация тестовых шаблонов для scan-тестирования.

**Baud rate** — скорость передачи в бодах, то есть число символов
в секунду. Для UART совпадает с числом бит в секунду, включая
служебные.

**Break** — обрыв, состояние линии 0 длительностью больше кадра.
Фиксируется флагом `BE` и прерыванием `UARTBEINTR`.

**CTS** — Clear To Send, сигнал готовности принимающей стороны.
Вход `nUARTCTS` активен низким уровнем.

**DCD** — Data Carrier Detect, сигнал обнаружения несущей.
Вход `nUARTDCD` активен низким уровнем.

**DMA** — Direct Memory Access, прямой доступ к памяти. Контроллер
DMA пересылает данные между FIFO и памятью без участия процессора.

**DSR** — Data Set Ready, сигнал готовности удалённого устройства.
Вход `nUARTDSR` активен низким уровнем.

**EBI** — External Bus Interface, внешний параллельный интерфейс,
через который подаются тестовые векторы.

**FIFO** — First In First Out, буфер, из которого данные читаются
в порядке поступления. В PL011 глубина 16 символов.

**Framing error** — ошибка кадра: стоп-бит принят в состоянии 0.
Фиксируется флагом `FE`.

**Half-duplex** — полудуплекс, режим поочерёдной передачи и приёма.
Обычный режим для IrDA SIR.

**Full-duplex** — полный дуплекс, одновременные передача и приём.

**IrDA** — Infrared Data Association, организация, задающая
стандарты инфракрасной связи. PL011 поддерживает SIR.

**LBE** — Loop Back Enable, бит 7 регистра `UARTCR`. Включает
шлейф: передаваемые данные возвращаются в приёмник.

**Modem** — модем; в контексте UART — совокупность сигналов
`nUARTCTS`, `nUARTDCD`, `nUARTDSR`, `nUARTRI`, `nUARTDTR`,
`nUARTRTS`, `nUARTOut1`, `nUARTOut2`.

**Overrun** — переполнение принимающего FIFO: новый символ пришёл,
когда буфер был полон, и данные потеряны. Флаг `OE`.

**Parity** — бит чётности, служащий для обнаружения одиночных
ошибок. Может быть чётным, нечётным или отсутствовать.

**PrimeCell** — семейство периферийных компонентов ARM, к которому
относится PL011. Идентифицируется значением `0xB105F00D`.

**RI** — Ring Indicator, сигнал входящего звонка. Вход `nUARTRI`
активен низким уровнем.

**RTS** — Request To Send, сигнал запроса передачи. Выход
`nUARTRTS` активен низким уровнем.

**Scan-тест** — метод производственного тестирования, при котором
шаблоны сдвигаются в внутренние триггеры через scan-цепочки.

**SIR** — Serial Infrared, последовательный инфракрасный интерфейс
со скоростями до 115,2 кбит/с. Кодирование — импульсами
длительностью 3/16 бита.

**TIC** — Test Interface Controller, контроллер тестового
интерфейса, ведущее устройство на шине AMBA при подаче векторов.

**Trickbox** — внешняя «ловушка», соединяющая выходы кристалла
с его входами при интеграционном тестировании.

**UART** — Universal Asynchronous Receiver/Transmitter,
универсальный асинхронный приёмопередатчик.

**Word length** — длина слова данных в кадре: 5, 6, 7 или 8 бит.
Задаётся полем `WLEN` в `UARTLCR_H`.

**Асинхронный** — без общей тактовой линии; приёмник
синхронизируется по стартовому биту.

**Делитель** — коэффициент, задающий скорость передачи. Состоит
из целой (`UARTIBRD`) и дробной (`UARTFBRD`) частей.

**Кадр** — последовательность стартового бита, битов данных,
возможно бита чётности и стоп-битов.

**Маркер** — состояние линии в покое: 1 для `UARTTXD`
и `SIRIN`, 0 для `nSIROUT`.

**Передискретизация** — приём с частотой, кратной скорости передачи.
PL011 использует 16-кратную передискретизацию.

**Пробел** — состояние линии, противоположное маркеру: 0
для `UARTTXD` и `SIRIN`; активный импульс для `nSIROUT`.

**Тайм-аут приёма** — прерывание, возникающее, когда в FIFO есть
данные, но новых поступлений нет 32 такта `UARTCLK`.
