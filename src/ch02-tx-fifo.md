# 2.2.4. Передающий FIFO

Передающий FIFO — буфер между процессором и передающей логикой. Он
сглаживает неравномерность записи: процессор может записать несколько
символов подряд, а логика выдаёт их на линию с заданной скоростью.

## Параметры

| Параметр | Значение |
|----------|----------|
| Глубина | 16 записей |
| Разрядность записи | 8 бит данных |
| Управление | Бит `FEN` (`UARTLCR_H[4]`) |
| Уровни прерывания | `UARTIFLS[2:0]` |

## Режимы

**FIFO включён (`FEN = 1`).** Буфер хранит до 16 символов. Флаги `TXFE`
и `TXFF` в `UARTFR` отражают состояние всего FIFO.

**FIFO выключен (`FEN = 0`).** Буфер превращается в один удерживающий
регистр глубиной 1 символ. Флаги `TXFE` и `TXFF` отражают состояние
этого регистра.

## Запись

Запись в `UARTDR` помещает символ в FIFO (или в удерживающий регистр).
Если FIFO заполнен, запись игнорируется, а в `UARTFR` установлен `TXFF` —
программное обеспечение должно дождаться освобождения места. Запись
в `UARTDR` одновременно запускает передачу, если передающая логика
свободна.

## Прерывание передачи

Прерывание `UARTTXINTR` формируется по пересечению уровнем заполнения
порога, заданного `UARTIFLS[2:0]`, а не по самому уровню. Порог
отсчитывается от пустого FIFO:

| `TXIFLSEL` | Срабатывание |
|------------|--------------|
| `000` | FIFO заполнен не более чем на 1/8 |
| `001` | не более 1/4 |
| `010` | не более 1/2 |
| `011` | не более 3/4 |
| `100` | не более 7/8 |

Значения `101`–`111` зарезервированы. После сброса выбран порог 1/2
(`UARTIFLS = 0x12`).

## Взаимодействие с DMA

При включённом DMA (`UARTDMACR[1] = 1`) контроллер выставляет запрос
`UARTTXDMASREQ`, когда в FIFO появляется место. Контроллер DMA сам
переписывает данные из памяти, не загружая процессор.

## Очистка

Отдельной команды сброса FIFO нет. Чтобы очистить передающий FIFO,
нужно выключить FIFO битом `FEN = 0` — содержимое при этом теряется.
Делать это следует только при выключенном UART, иначе целостность
передаваемых данных не гарантируется.
