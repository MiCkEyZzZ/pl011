# 3.4. Прерывания

В контроллере формируется одиннадцать маскируемых источников прерываний.
Они объединяются в пять отдельных выходов и один общий, представляющий
собой логическое ИЛИ пяти выходов.

## Выходы прерываний

| Выход | Состав | Назначение |
|-------|--------|------------|
| `UARTMSINTR` | `UARTRIINTR`, `UARTCTSINTR`, `UARTDCDINTR`, `UARTDSRINTR` | Изменение модемных линий |
| `UARTRXINTR` | `UARTRXINTR` | Заполнение принимающего FIFO |
| `UARTTXINTR` | `UARTTXINTR` | Освобождение передающего FIFO |
| `UARTRTINTR` | `UARTRTINTR` | Тайм-аут приёма |
| `UARTEINTR` | `UARTOEINTR`, `UARTBEINTR`, `UARTPEINTR`, `UARTFEINTR` | Ошибки приёма |
| `UARTINTR` | ИЛИ пяти выходов выше | Объединённое прерывание |

## Источники внутри UARTMSINTR

| Источник | Причина |
|----------|---------|
| `UARTRIINTR` | Изменение уровня `nUARTRI` |
| `UARTCTSINTR` | Изменение уровня `nUARTCTS` |
| `UARTDCDINTR` | Изменение уровня `nUARTDCD` |
| `UARTDSRINTR` | Изменение уровня `nUARTDSR` |

## Источники внутри UARTEINTR

| Источник | Причина |
|----------|---------|
| `UARTOEINTR` | Переполнение принимающего FIFO |
| `UARTBEINTR` | Обрыв линии (break) |
| `UARTPEINTR` | Ошибка чётности |
| `UARTFEINTR` | Ошибка кадра |

## Разрешение прерываний

Каждый источник маскируется отдельным битом `UARTIMSC`. Запись единицы
в бит разрешает прерывание, запись нуля запрещает. После сброса все
маски сняты.

## Разделение потоковых и статусных прерываний

Прерывания передачи и приёма (`UARTTXINTR`, `UARTRXINTR`) отделены
от статусных. Это позволяет строить драйвер так, чтобы данные читались
и записывались по достижении порогов FIFO, а ошибки и изменения
модемных линий обрабатывались отдельно.

## Варианты подключения

| Схема | Как используется |
|-------|------------------|
| Общее прерывание | `UARTINTR` подключён к контроллеру прерываний, обработчик читает `UARTMIS` |
| Раздельные линии | Каждый выход подключён отдельно, обработчики независимы |
| Смешанная | Данные — по `UARTINTR`, ошибки — по `UARTEINTR` |

## Чтение состояния

Состояние источников доступно в двух видах:

| Регистр | Что показывает |
|---------|----------------|
| `UARTRIS` | Сырое состояние, без учёта маски |
| `UARTMIS` | Состояние после маски, определяет выходы |

## Сброс флагов

Флаги снимаются записью единицы в соответствующий бит `UARTICR`.
Часть флагов снимается автоматически при изменении состояния FIFO
(подробнее в разделе 3.3.13).
