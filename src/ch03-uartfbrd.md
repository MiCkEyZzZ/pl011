# 3.3.6. Дробный делитель UARTFBRD

`UARTFBRD` — 6-битный регистр чтения/записи, содержащий дробную часть
делителя скорости передачи.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x028` |
| Тип | RW |
| Ширина | 6 бит |
| Значение после сброса | `0x00` |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 5:0 | `BAUD DIVFRAC` | Дробная часть делителя, шаг 1/64 |

## Формула

```text
BaudDIV = UARTIBRD + UARTFBRD / 64
```

Дробная часть вычисляется с округлением:

```text
UARTFBRD = round((BaudDIV − UARTIBRD) × 64)
```

## Пример расчёта

Требуется 230400 бод при `UARTCLK = 4 МГц`:

```text
BaudDIV = 4 000 000 / (16 × 230 400) = 1,085
UARTIBRD = 1
дробная часть = 0,085
UARTFBRD = round(0,085 × 64) = 5
фактический делитель = 1 + 5/64 = 1,078
фактическая скорость = 4 000 000 / (16 × 1,078) = 231 911 бод
погрешность = 0,656 %
```

## Максимальная погрешность

При шаге 1/64 максимальная относительная погрешность составляет:

```text
1/64 × 100 % ≈ 1,56 %
```

Худший случай — `UARTFBRD = 1`, когда ошибка накапливается за 64 такта.
Для большинства практических скоростей погрешность значительно меньше.

## Типовые значения при 4 МГц

| `UARTIBRD` | `UARTFBRD` | Требуется, бод | Получается, бод | Ошибка, % |
|------------|------------|----------------|-----------------|-----------|
| `0x1` | `0x5` | 230400 | 231911 | 0,656 |
| `0x2` | `0xB` | 115200 | 115101 | 0,086 |
| `0x3` | `0x10` | 76800 | 76923 | 0,160 |
| `0x6` | `0x21` | 38400 | 38369 | 0,081 |
| `0x11` | `0x17` | 14400 | 14401 | 0,007 |
| `0x68` | `0xB` | 2400 | 2400 | ~0 |
| `0x8E0` | `0x2F` | 110 | 110 | ~0 |

## Когда можно обойтись нулём

Если `UARTCLK` кратна `16 × Baud rate`, дробная часть равна нулю.
Именно поэтому выбирают частоты вроде 7,3728 МГц: при них стандартные
скорости получаются целыми делителями.

## Применение значения

Как и `UARTIBRD`, регистр не обновляется до завершения текущего символа.
Для применения нужно выполнить запись в `UARTLCR_H` — она фиксирует
все три регистра (`UARTIBRD`, `UARTFBRD`, `UARTLCR_H`) одновременно.

## Замечание о 1,5 стоп-бита

Некоторые UART поддерживают 1,5 стоп-бита. PL011 — нет: бит `STP2`
задаёт либо один, либо два стоп-бита.
