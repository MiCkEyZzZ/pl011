# 4.5. Тестирование входов

Интеграционное тестирование входов проверяет, что каждый входной
сигнал доходит до внутренней логики. Проверка делится на две части:

- внутрикристальные входы;
- первичные входы (выводы кристалла).

## Общий принцип

Для входов используется наблюдение: значение, поданное на линию,
читается через тестовый регистр. Если прочитанное совпадает
с поданным, соединение исправно.

| Группа | Регистр | Способ проверки |
|--------|---------|-----------------|
| Внутрикристальные | `UARTITIP[7:6]` | Запись значения и чтение его обратно |
| Первичные | `UARTITIP[5:0]` | Шлейф с выходов через внешнюю ловушку |

## Порядок

```text
1. Установить ITEN = 1 в UARTTCR.
2. Для внутрикристальных входов — писать и читать UARTITIP[7:6].
3. Для первичных входов — подавать значения через UARTITOP[5:0]
   и читать их в UARTITIP[5:0].
4. Снять ITEN.
```

## Ограничения

- Модемные входы и входы последовательных данных доступны только
  для чтения.
- Для первичных входов обязателен внешний шлейф: без него проверить
  соединение с выводом нельзя.
