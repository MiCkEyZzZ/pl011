# 3.3.9. Выбор уровня FIFO UARTIFLS

`UARTIFLS` задаёт уровни заполнения FIFO, при пересечении которых
формируются прерывания `UARTRXINTR` и `UARTTXINTR`.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x034` |
| Тип | RW |
| Ширина | 6 бит |
| Значение после сброса | `0x12` |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 15:6 | — | Зарезервировано, читается как ноль |
| 5:3 | `RXIFLSEL` | Порог прерывания приёма |
| 2:0 | `TXIFLSEL` | Порог прерывания передачи |

## Порог приёма

| `RXIFLSEL` | Срабатывание |
|------------|--------------|
| `000` | FIFO заполнен не менее чем на 1/8 |
| `001` | не менее 1/4 |
| `010` | не менее 1/2 |
| `011` | не менее 3/4 |
| `100` | не менее 7/8 |
| `101`–`111` | Зарезервировано |

## Порог передачи

| `TXIFLSEL` | Срабатывание |
|------------|--------------|
| `000` | FIFO заполнен не более чем на 1/8 |
| `001` | не более 1/4 |
| `010` | не более 1/2 |
| `011` | не более 3/4 |
| `100` | не более 7/8 |
| `101`–`111` | Зарезервировано |

## Срабатывание по пересечению

Прерывания формируются не по уровню, а по **пересечению** порога.
Это важно: если FIFO уже находится выше порога, прерывание не будет
устанавливаться повторно на каждом такте. Оно возникает в момент,
когда уровень проходит порог в соответствующем направлении.

## Значение после сброса

`UARTIFLS = 0x12`:

```text
0x12 = 0b010010
TXIFLSEL = 010 (1/2)
RXIFLSEL = 010 (1/2)
```

То есть оба порога установлены на половину заполнения.

## Практические рекомендации

- Порог **приёма** лучше выбирать не слишком высоким: при 3/4 или 7/8
  остаётся мало запаса до переполнения.
- Порог **передачи** определяет, насколько заранее процессор получает
  прерывание на дозапись. При высоких скоростях его стоит понизить
  (например, до 1/4), чтобы успеть записать данные.
- При использовании DMA эти же пороги определяют моменты выставления
  пакетных запросов.

## Пример

```c
/* Приём: порог 1/4; передача: порог 1/4 */
*(volatile uint32_t *)(UART_BASE + 0x034) = (1u << 3) | 1u;
```
