# 2.2.2. Блок регистров

Блок регистров содержит все программно-доступные регистры контроллера.
С ним работает интерфейс APB: любое обращение по шине адресуется одному
из регистров этого блока.

## Карта регистров

| Смещение | Регистр | Тип | Назначение |
|----------|---------|-----|------------|
| `0x000` | `UARTDR` | RW | Данные (передача и приём) |
| `0x004` | `UARTRSR`/`UARTECR` | RW | Статус приёма / сброс ошибок |
| `0x018` | `UARTFR` | RO | Флаги |
| `0x020` | `UARTILPR` | RW | Делитель IrDA низкого потребления |
| `0x024` | `UARTIBRD` | RW | Целый делитель скорости |
| `0x028` | `UARTFBRD` | RW | Дробный делитель скорости |
| `0x02C` | `UARTLCR_H` | RW | Управление линией |
| `0x030` | `UARTCR` | RW | Управление |
| `0x034` | `UARTIFLS` | RW | Уровни срабатывания FIFO |
| `0x038` | `UARTIMSC` | RW | Маска прерываний |
| `0x03C` | `UARTRIS` | RO | Сырой статус прерываний |
| `0x040` | `UARTMIS` | RO | Маскированный статус прерываний |
| `0x044` | `UARTICR` | WO | Сброс прерываний |
| `0x048` | `UARTDMACR` | RW | Управление DMA |
| `0x080`–`0x08C` | Тестовые регистры | RW | Тестовая обвязка |
| `0xFE0`–`0xFEC` | `UARTPeriphID0-3` | RO | Идентификация периферии |
| `0xFF0`–`0xFFC` | `UARTPCellID0-3` | RO | Идентификация PrimeCell |

Полное описание каждого регистра — в главе 3.

## Объединённый регистр UARTLCR

`UARTLCR_H`, `UARTIBRD` и `UARTFBRD` образуют один внутренний 30-битный
регистр `UARTLCR`. Он обновляется по одному стробирующему сигналу, который
формируется при записи в `UARTLCR_H`.

Практическое следствие: чтобы изменение делителей вступило в силу,
после записи в `UARTIBRD` или `UARTFBRD` нужно выполнить запись
в `UARTLCR_H`. Возможны две последовательности:

```text
  UARTIBRD → UARTFBRD → UARTLCR_H
  UARTFBRD → UARTIBRD → UARTLCR_H
```

Для изменения только одного делителя достаточно его записи и последующей
записи в `UARTLCR_H`.

## Сброс

Большинство регистров сбрасываются сигналом `PRESETn`. Значения после
сброса приведены в таблице главы 3. Обратите внимание на исключения:

- `UARTCR` после сброса равен `0x00000300`: биты `TXE` и `RXE` установлены,
  а сам UART выключен (`UARTEN = 0`);
- `UARTFR` после сброса имеет установленные биты `TXFE` и `RXFE`;
- `UARTIFLS` после сброса равен `0x12` — половина заполнения FIFO;
- модемные биты регистров `UARTRIS` и `UARTMIS` после сброса не определены.

## Зарезервированные адреса

Обращения по адресам, не занятым регистрами, не выполняют записи
и возвращают неопределённое значение при чтении. Программное обеспечение
не должно использовать эти адреса.
