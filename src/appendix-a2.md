# A.2. Внутрикристальные сигналы

Помимо сигналов APB контроллеру требуется ряд внутрикристальных
сигналов: тактирование, сброс, прерывания, DMA и scan-тест.

## Тактирование

Обязателен свободно работающий опорный тактовый сигнал `UARTCLK`.
По умолчанию он считается асинхронным по отношению к `PCLK`.

Частота `UARTCLK` должна лежать в диапазоне от 1,42 МГц до 542,72 МГц.
Это гарантирует, что длительность импульса передачи в режиме низкого
потребления соответствует спецификации IrDA SIR.

## Сброс

Входы сброса устанавливаются асинхронно, но снимаются синхронно
для каждого тактового домена. Это гарантирует сброс логики даже при
отсутствии тактов и предотвращает проблемы статического потребления
при включении питания.

У каждого домена свой сброс — это упрощает вставку scan-ячеек.

## Таблица сигналов

| Имя | Тип | Источник или приёмник | Описание |
|-----|-----|-----------------------|----------|
| `UARTCLK` | Вход | Генератор тактов | Опорный тактовый сигнал UART |
| `nUARTRST` | Вход | Контроллер сброса | Сброс домена `UARTCLK`, активный низкий; устанавливается асинхронно по `PRESETn`, снимается синхронно с `UARTCLK` |
| `UARTMSINTR` | Выход | Контроллер прерываний | Прерывание состояния модема, активное высокое |
| `UARTRXINTR` | Выход | Контроллер прерываний | Прерывание принимающего FIFO |
| `UARTTXINTR` | Выход | Контроллер прерываний | Прерывание передающего FIFO |
| `UARTRTINTR` | Выход | Контроллер прерываний | Прерывание тайм-аута приёма |
| `UARTEINTR` | Выход | Контроллер прерываний | Прерывание ошибок |
| `UARTINTR` | Выход | Контроллер прерываний | Объединённое прерывание, ИЛИ пяти предыдущих |
| `UARTTXDMASREQ` | Выход | Контроллер DMA | Одиночный запрос DMA передачи |
| `UARTTXDMABREQ` | Выход | Контроллер DMA | Пакетный запрос DMA передачи |
| `UARTRXDMASREQ` | Выход | Контроллер DMA | Одиночный запрос DMA приёма |
| `UARTRXDMABREQ` | Выход | Контроллер DMA | Пакетный запрос DMA приёма |
| `UARTTXDMACLR` | Вход | Контроллер DMA | Сброс запросов передачи; при пакетной передаче выставляется на последнем слове пакета |
| `UARTRXDMACLR` | Вход | Контроллер DMA | Сброс запросов приёма; при пакетном приёме выставляется на последнем слове пакета |
| `SCANENABLE` | Вход | Контроллер теста | Разрешение scan-теста для обоих доменов |
| `SCANINPCLK` | Вход | Контроллер теста | Вход scan-цепочки домена `PCLK` |
| `SCANINUCLK` | Вход | Контроллер теста | Вход scan-цепочки домена `UARTCLK` |
| `SCANOUTPCLK` | Выход | Контроллер теста | Выход scan-цепочки домена `PCLK` |
| `SCANOUTUCLK` | Выход | Контроллер теста | Выход scan-цепочки домена `UARTCLK` |

## Замечание о сбросе

Контроллер сброса должен формировать `nUARTRST` на основе `PRESETn`:
устанавливать асинхронно, снимать синхронно с `UARTCLK`. Нарушение
этого правила приводит к неопределённому состоянию триггеров
в домене `UARTCLK`.
