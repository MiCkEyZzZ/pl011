# 3.3.3. Регистр флагов UARTFR

`UARTFR` — регистр флагов, только для чтения. Он показывает состояние
FIFO, передатчика и модемных входов.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x018` |
| Тип | RO |
| Ширина | 9 бит |
| Значение после сброса | `0b-10010---` |

После сброса `TXFF`, `RXFF` и `BUSY` равны 0, а `TXFE` и `RXFE` — 1.

## Битовые поля

| Бит | Имя | Описание |
|-----|-----|----------|
| 15:9 | — | Зарезервировано, читается как ноль |
| 8 | `RI` | Индикатор звонка: 1, когда `nUARTRI = 0` |
| 7 | `TXFE` | Передающий FIFO пуст |
| 6 | `RXFF` | Принимающий FIFO полон |
| 5 | `TXFF` | Передающий FIFO полон |
| 4 | `RXFE` | Принимающий FIFO пуст |
| 3 | `BUSY` | Идёт передача |
| 2 | `DCD` | 1, когда `nUARTDCD = 0` |
| 1 | `DSR` | 1, когда `nUARTDSR = 0` |
| 0 | `CTS` | 1, когда `nUARTCTS = 0` |

## Зависимость от режима FIFO

Значение флагов `TXFE`, `TXFF`, `RXFE`, `RXFF` зависит от бита `FEN`:

| Флаг | `FEN = 0` | `FEN = 1` |
|------|-----------|-----------|
| `TXFE` | Удерживающий регистр пуст | Весь FIFO пуст |
| `TXFF` | Удерживающий регистр полон | Весь FIFO полон |
| `RXFE` | Удерживающий регистр пуст | Весь FIFO пуст |
| `RXFF` | Удерживающий регистр полон | Весь FIFO полон |

## Флаг BUSY

`BUSY` устанавливается, как только передающий FIFO становится непустым,
независимо от того, включён UART или нет. Снимается после того, как
из сдвигового регистра ушёл последний стоп-бит.

Важно: `TXFE = 1` не означает, что передача завершена. Данные могут ещё
находиться в сдвиговом регистре. Чтобы дождаться полного окончания
передачи, нужно проверять `BUSY = 0`, а не `TXFE = 1`.

## Модемные флаги

Биты `CTS`, `DSR`, `DCD`, `RI` — инвертированные значения одноимённых
входов. Они проходят через синхронизатор и фильтр, поэтому изменение
становится видимым с задержкой в несколько тактов `PCLK`.

## Типичное использование

```c
/* Дождаться окончания передачи */
while (*(volatile uint32_t *)(UART_BASE + 0x018) & (1u << 3))
    ;
```

```c
/* Проверить, есть ли принятые данные */
if (!(*(volatile uint32_t *)(UART_BASE + 0x018) & (1u << 4)))
    ch = *(volatile uint32_t *)(UART_BASE + 0x000);
```
