# Приложение A. Описание сигналов

В приложении описаны сигналы, с которыми взаимодействует блок UART.
Все они разделены на три группы.

## Состав приложения

| Раздел | Группа сигналов |
|--------|-----------------|
| A.1 | Сигналы шины AMBA APB |
| A.2 | Внутрикристальные сигналы |
| A.3 | Сигналы выводов |

## Соглашения об именах

| Признак | Значение |
|---------|----------|
| Префикс `P` | Сигнал шины AMBA APB |
| Строчная `n` в начале | Активный низкий уровень |
| Прописные буквы | Сокращение из названия сигнала |
| Суффикс `INTR` | Прерывание |
| Суффикс `DMASREQ` | Одиночный запрос DMA |
| Суффикс `DMABREQ` | Пакетный запрос DMA |
| Суффикс `DMACLR` | Сброс запроса DMA |

## Уровни активности

- Сигналы AMBA APB активны высоким уровнем.
- Модемные сигналы (`nUARTCTS`, `nUARTDCD`, `nUARTDSR`, `nUARTRI`,
  `nUARTDTR`, `nUARTRTS`, `nUARTOut1`, `nUARTOut2`) активны низким.
- `nSIROUT` активен низким уровнем: единица на этой линии означает
  инфракрасный импульс, то есть логический 0 в линии IrDA.
- Прерывания и запросы DMA активны высоким уровнем.
