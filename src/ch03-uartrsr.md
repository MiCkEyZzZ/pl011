# 3.3.2. UARTRSR/UARTECR

По одному адресу расположены два регистра: `UARTRSR` (статус приёма,
только чтение) и `UARTECR` (сброс ошибок, только запись).

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x004` |
| Тип | RW |
| Ширина | 4 бита при чтении, 0 бит при записи |
| Значение после сброса | `0x0` |

## Битовые поля при чтении (UARTRSR)

| Биты | Имя | Описание |
|------|-----|----------|
| 7:4 | — | Зарезервировано, при чтении не определено |
| 3 | `OE` | Переполнение приёмного FIFO |
| 2 | `BE` | Обрыв линии |
| 1 | `PE` | Ошибка чётности |
| 0 | `FE` | Ошибка кадра |

## Запись (UARTECR)

Любая запись в этот адрес сбрасывает признаки `FE`, `PE`, `BE` и `OE`
в ноль. Значение записываемых данных не важно — важен сам факт записи.

```c
*(volatile uint32_t *)(UART_BASE + 0x004) = 0;   /* сбросить все ошибки */
```

## Связь с UARTDR

Признаки в `UARTRSR` относятся к последнему символу, прочитанному
из `UARTDR`. Поэтому порядок обращения строгий:

```text
1. Прочитать UARTDR  → получен символ и его признаки в битах [11:8]
2. Прочитать UARTRSR → те же признаки отдельно
```

Обратный порядок недопустим: `UARTRSR` обновляется только при чтении
`UARTDR`, поэтому до чтения данных он содержит сведения о предыдущем
символе.

Исключение — признак `OE`: он устанавливается сразу в момент переполнения,
не дожидаясь чтения данных.

## Описание признаков

**`OE` — переполнение.** Устанавливается, когда символ принят при полном
FIFO. Содержимое FIFO при этом не портится: теряется только новый символ.
Сбрасывается записью в `UARTECR`; также автоматически снимается, когда
в FIFO появляется свободное место и в него записывается новый символ.

**`BE` — обрыв.** Линия удерживалась в нуле дольше полного кадра.
В FIFO при этом загружается один нулевой символ, а следующий приём
возобновляется только после возврата линии в единицу.

**`PE` — ошибка чётности.** Чётность принятого символа не совпала
с заданной полями `PEN`, `EPS`, `SPS`.

**`FE` — ошибка кадра.** В позиции стоп-бита обнаружен ноль. Обычно
означает расхождение скоростей или помеху.

## Особенность сброса

Запись в `UARTECR` сбрасывает и `OE`, и остальные признаки одновременно.
Раздельного сброса не предусмотрено.
