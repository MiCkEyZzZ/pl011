# 4.4.3. UARTITOP

`UARTITOP` — регистр чтения и установки выходов интеграционного
теста. В режиме интеграционного теста он позволяет задавать значения
на выходных линиях и читать их обратно.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x088` |
| Тип | RW |
| Ширина | 14 бит по сводке (фактически используются 16) |
| Значение после сброса | `0x000` |

## Битовые поля

| Бит | Имя | Тип | Описание |
|-----|-----|-----|----------|
| 15 | `UARTTXDMASREQ` | Внутрикристальный | Одиночный запрос DMA передачи |
| 14 | `UARTTXDMABREQ` | Внутрикристальный | Пакетный запрос DMA передачи |
| 13 | `UARTRXDMASREQ` | Внутрикристальный | Одиночный запрос DMA приёма |
| 12 | `UARTRXDMABREQ` | Внутрикристальный | Пакетный запрос DMA приёма |
| 11 | `UARTMSINTR` | Внутрикристальный | Прерывание модема |
| 10 | `UARTRXINTR` | Внутрикристальный | Прерывание приёма |
| 9 | `UARTTXINTR` | Внутрикристальный | Прерывание передачи |
| 8 | `UARTRTINTR` | Внутрикристальный | Прерывание тайм-аута |
| 7 | `UARTEINTR` | Внутрикристальный | Прерывание ошибок |
| 6 | `UARTINTR` | Внутрикристальный | Объединённое прерывание |
| 5 | `nUARTOut2` | Первичный | Выход `nUARTOut2` |
| 4 | `nUARTOut1` | Первичный | Выход `nUARTOut1` |
| 3 | `nUARTRTS` | Первичный | Выход `nUARTRTS` |
| 2 | `nUARTDTR` | Первичный | Выход `nUARTDTR` |
| 1 | `nSIROUT` | Первичный | Выход `nSIROUT` |
| 0 | `UARTTXD` | Первичный | Выход `UARTTXD` |

## Доступ

Внутрикристальные выходы (биты 15:6) доступны для чтения и записи.
Первичные выходы (биты 5:0) также управляются записью в режиме
интеграционного теста; чтение возвращает значение на выходе тестового
мультиплексора.

## Пример

```c
#define UART_ITOP   (UART_BASE + 0x088)

/* Выставить UARTTXD = 1 и nUARTRTS = 1 */
*(volatile uint32_t *)UART_ITOP = (1u << 0) | (1u << 3);

/* Прочитать состояние выходов */
uint32_t outputs = *(volatile uint32_t *)UART_ITOP;
```

## Замечание о ширине

В сводной таблице регистр указан как 14-битный, однако в описании
полей используются биты с 0 по 15. Расхождение связано с тем, что
сводка учитывает только часть линий. При работе следует
руководствоваться картой битов, а не значением ширины.

## Применение

- Подача значений на выходы при автономном тесте.
- Переключение линий контроллера DMA и прерываний при тесте
  в составе системы.
- Проверка шлейфа «выход → вход» через `UARTITIP`.
