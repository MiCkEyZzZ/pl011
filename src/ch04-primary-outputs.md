# 4.6.2. Первичные выходы

Первичные выходы — сигналы, выходящие на выводы кристалла. Они
проверяются совместно с первичными входами через внешнюю ловушку.

## Список выходов

| Сигнал | Бит `UARTITOP` |
|--------|----------------|
| `UARTTXD` | 0 |
| `nSIROUT` | 1 |
| `nUARTDTR` | 2 |
| `nUARTRTS` | 3 |
| `nUARTOut1` | 4 |
| `nUARTOut2` | 5 |

## Порядок проверки

```text
1. Выходы соединяются со входами через ловушку:
   UARTTXD -> UARTRXD, nSIROUT -> SIRIN,
   nUARTRTS -> nUARTCTS, nUARTOUT1 -> nUARTDCD,
   nUARTDTR -> nUARTDSR, nUARTOUT2 -> nUARTRI.
2. Записать 1 в ITEN.
3. Подать различные комбинации битов через UARTITOP.
4. Прочитать результат через UARTITIP.
5. Сравнить с поданным.
```

## Проверяемые комбинации

Полезно прогнать не только все нули и все единицы, но и «шагающую»
единицу — по одному биту за раз:

```text
0x01, 0x02, 0x04, 0x08, 0x10, 0x20
```

Так выявляются перепутанные и закороченные между собой линии.

## Замечание об активных уровнях

Модемные выходы активны низким уровнем. При проверке это не мешает:
важно лишь, что поданное значение читается без инверсии на входе.
Если инверсия есть, значит, в тракте появился лишний инвертор.

## Ограничение

Без внешней ловушки проверить первичные выходы нельзя: прочитать
значение с вывода внутрь кристалла можно только через
соответствующий вход.
