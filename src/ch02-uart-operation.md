# 2.4.3. Работа UART

В штатном режиме UART выполняет две независимые операции: передачу
и приём. Обе работают от общего генератора скорости и могут идти
одновременно.

## Передача

1. Программное обеспечение записывает символ в `UARTDR`.
2. Символ помещается в передающий FIFO.
3. Передающая логика извлекает символ, формирует кадр и выдаёт его
   на линию `TXD` со скоростью, заданной делителями.
4. После передачи последнего стоп-бита снимается флаг `BUSY`.

Если FIFO заполнен, запись не выполняется, а в `UARTFR` установлен `TXFF`.
Программное обеспечение должно дождаться освобождения места, например
по прерыванию `UARTTXINTR` или опросом флага.

## Приём

1. Принимающая логика обнаруживает стартовый бит на линии `RXD`.
2. Выбирает биты данных, бит чётности и стоп-биты.
3. Проверяет кадр и чётность, формирует признаки ошибок.
4. Помещает символ и признаки в принимающий FIFO.
5. Программное обеспечение читает `UARTDR`.

Если FIFO пуст, установлен флаг `RXFE`. Если FIFO полон, новый символ
теряется, а в `UARTRSR` устанавливается признак `OE`.

## Флаги состояния

| Флаг | Бит `UARTFR` | Смысл |
|------|--------------|-------|
| `TXFE` | 7 | Передающий FIFO пуст |
| `RXFF` | 6 | Принимающий FIFO полон |
| `TXFF` | 5 | Передающий FIFO полон |
| `RXFE` | 4 | Принимающий FIFO пуст |
| `BUSY` | 3 | Идёт передача |

## Полный дуплекс

Передача и приём независимы: можно одновременно передавать и принимать.
Единственное ограничение — физическая линия: в некоторых схемах
(например, на шине RS-485) приём и передача используют одну пару
проводов, и направление нужно переключать программно или внешней схемой.

## Режим петли

При `LBE = 1` выход передающей логики замыкается на вход принимающей.
Это позволяет проверить весь тракт без внешнего устройства: записанный
символ должен быть прочитан обратно. Модемные выходы при этом также
замыкаются на модемные входы.

## Пример опроса

```c
/* Отправить один символ, дождавшись места в FIFO */
while (*(volatile uint32_t *)(UART_BASE + 0x018) & (1u << 5))
    ;                                  /* ждём, пока TXFF = 0 */
*(volatile uint32_t *)(UART_BASE + 0x000) = ch;

/* Принять символ, дождавшись данных */
while (*(volatile uint32_t *)(UART_BASE + 0x018) & (1u << 4))
    ;                                  /* ждём, пока RXFE = 0 */
ch = *(volatile uint32_t *)(UART_BASE + 0x000) & 0xFF;
```

Опрос в цикле прост, но занимает процессор. На высоких скоростях
эффективнее прерывания или DMA.
