# 2.2.3. Генератор скорости передачи

Генератор скорости формирует внутренний сигнал `Baud16`, частота которого
ровно в 16 раз превышает скорость передачи в бодах. Из него передающая
и принимающая логика получают битовый интервал.

## Формула

```text
BaudDIV = UARTCLK / (16 × Baud rate)
```

`BaudDIV` состоит из двух частей:

| Часть | Регистр | Разрядность | Смысл |
|-------|---------|-------------|-------|
| Целая | `UARTIBRD[15:0]` | 16 бит | `BAUD DIVINT` |
| Дробная | `UARTFBRD[5:0]` | 6 бит | `BAUD DIVFRAC`, шаг 1/64 |

Итоговое значение:

```text
BaudDIV = UARTIBRD + UARTFBRD / 64
Baud16  = UARTCLK / BauddIV
Baud rate = UARTCLK / (16 × BauddIV)
```

## Ограничения

- Минимальный делитель равен 1: `UARTIBRD = 0` недопустим, при этом
  `UARTFBRD` игнорируется.
- Максимальный делитель равен 65535 (`0xFFFF`). Если `UARTIBRD = 0xFFFF`,
  то `UARTFBRD` должен быть равен нулю; иначе передача или приём
  прерываются.
- Новые значения делителей не применяются до завершения передачи или
  приёма текущего символа.

## Пример расчёта

Требуется 230400 бод при `UARTCLK = 4 МГц`:

```text
BaudDIV = 4 000 000 / (16 × 230 400) = 1,085
UARTIBRD = 1
дробная часть m = round(0,085 × 64) = 5
фактический делитель = 1 + 5/64 = 1,078
фактическая скорость = 4 000 000 / (16 × 1,078) = 231 911 бод
погрешность = 0,656 %
```

## Точность

Дробный делитель с шагом 1/64 даёт максимальную погрешность около 1,56 %
(при `m = 1`), причём ошибка накапливается за 64 такта. Для большинства
скоростей погрешность значительно меньше.

Для асинхронного обмена суммарное расхождение скоростей передатчика
и приёмника обычно не должно превышать 2–3 %, поэтому точности PL011
достаточно почти всегда.

## Типовые значения

При `UARTCLK = 7,3728 МГц` (частота, кратная стандартным скоростям)
дробная часть не нужна:

| `UARTIBRD` | Скорость, бод |
|------------|---------------|
| `0x1` | 460800 |
| `0x2` | 230400 |
| `0x4` | 115200 |
| `0x8` | 57600 |
| `0xC` | 38400 |
| `0x18` | 19200 |
| `0x30` | 9600 |
| `0xC0` | 2400 |
| `0x180` | 1200 |
| `0x105D` | 110 |

## Второй делитель

Помимо `Baud16`, генератор формирует сигнал `IrLPBaud16`, используемый
блоком IrDA в режиме низкого потребления. Его частота задаётся отдельным
делителем `UARTILPR` и должна лежать в диапазоне 1,42–2,12 МГц.
