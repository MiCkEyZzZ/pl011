# 4.4.4. UARTTDR

`UARTTDR` — тестовый регистр данных. Он позволяет записывать данные
непосредственно в принимающий FIFO и читать их из передающего FIFO.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x08C` |
| Тип | RW |
| Ширина | 11 бит |
| Значение после сброса | `0x---` |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 15:11 | — | Зарезервировано, при чтении не определено |
| 10:0 | `DATA` | Данные для записи в приёмный FIFO или чтения из передающего |

## Условие работы

Функция включается битом `TESTFIFO` (`UARTTCR[1]`). Пока он равен
нулю, доступ к FIFO через этот регистр невозможен.

| `TESTFIFO` | Поведение |
|------------|-----------|
| 0 | Обычная работа, `UARTTDR` не используется |
| 1 | Запись идёт в приёмный FIFO, чтение — из передающего |

## Пример

```c
#define UART_TCR   (UART_BASE + 0x080)
#define UART_TDR   (UART_BASE + 0x08C)

/* Включить тестовый доступ к FIFO */
*(volatile uint32_t *)UART_TCR = 2u;

/* Поместить символ в приёмный FIFO */
*(volatile uint32_t *)UART_TDR = 'A';

/* Прочитать символ из передающего FIFO */
uint32_t out = *(volatile uint32_t *)UART_TDR;

/* Вернуть обычный режим */
*(volatile uint32_t *)UART_TCR = 0u;
```

## Назначение

Регистр позволяет проверить:

- запись и чтение FIFO без обращения к последовательной линии;
- правильность работы флагов заполнения в `UARTFR`;
- логику порогов и прерываний при управляемом заполнении.

## Замечание о сбросе

Значение после сброса не определено (в таблице указано `0x---`),
так как регистр связан с содержимым FIFO, а не с отдельной ячейкой
памяти.
