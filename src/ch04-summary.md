# 4.7. Итоги интеграционного тестирования

В таблице собрана стратегия проверки для всех выводов контроллера.

## Стратегия по группам

| Группа | Стратегия |
|--------|-----------|
| Сброс и тактирование | Векторами не проверяются |
| Шина AMBA | Чтение и запись регистров |
| Прерывания и DMA (выходы) | Через `UARTITOP` |
| DMA (входы очистки) | Через `UARTITIP` |
| Выводы последовательных и модемных сигналов | Ловушка плюс `UARTITIP` и `UARTITOP` |
| Scan-сигналы | Векторами не проверяются |

## Выводы

1. Все сигналы данных и управления AMBA проверяются обычными
   обращениями к регистрам.
2. Прерывания и запросы DMA проверяются через регистры
   интеграционного теста.
3. Выводы последовательных и модемных сигналов требуют внешней
   ловушки.
4. Сброс, тактирование и scan-сигналы векторами не проверяются:
   их корректность обеспечивается на уровне интеграции.
