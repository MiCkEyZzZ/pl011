# 4.4.2. UARTITIP

`UARTITIP` — регистр чтения и установки входов интеграционного
теста. В режиме интеграционного теста он позволяет как читать,
так и задавать значения входных сигналов.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x084` |
| Тип | RW |
| Ширина | 8 бит |
| Значение после сброса | `0x00` |

## Битовые поля

| Бит | Имя | Доступ | Описание |
|-----|-----|--------|----------|
| 15:8 | — | — | Зарезервировано |
| 7 | `UARTTXDMACLR` | RW | Внутрикристальный вход очистки запроса DMA передачи |
| 6 | `UARTRXDMACLR` | RW | Внутрикристальный вход очистки запроса DMA приёма |
| 5 | `nUARTRI` | RO | Первичный вход `nUARTRI` |
| 4 | `nUARTDCD` | RO | Первичный вход `nUARTDCD` |
| 3 | `nUARTCTS` | RO | Первичный вход `nUARTCTS` |
| 2 | `nUARTDSR` | RO | Первичный вход `nUARTDSR` |
| 1 | `SIRIN` | RO | Первичный вход `SIRIN` |
| 0 | `UARTRXD` | RO | Первичный вход `UARTRXD` |

## Запись

Записывать можно только биты 7 и 6. Записанное значение определяет
уровень, который подаётся на внутрикристальные входы `UARTTXDMACLR`
и `UARTRXDMACLR` при `ITEN = 1`.

При `ITEN = 0` эти входы берутся с внешних выводов, а запись
в регистр на них не влияет.

```c
/* Подать 1 на UARTTXDMACLR и 0 на UARTRXDMACLR */
*(volatile uint32_t *)(UART_BASE + 0x084) = 1u << 7;
```

## Чтение

- Биты 7:6 возвращают значение на выходе тестового мультиплексора,
  то есть то, что реально подано на внутренние линии.
- Биты 5:0 напрямую отражают уровни первичных входов.

## Применение

| Проверка | Как выполняется |
|----------|-----------------|
| Автономный тест | `ITEN = 1`, запись 1 и 0 в биты 7:6 с последующим чтением |
| Тест в системе | `ITEN = 0`, переключение сигналов со стороны контроллера DMA и чтение через `UARTITIP` |

## Замечание

Модемные входы и входы данных доступны только для чтения: управлять
ими через этот регистр нельзя. Проверка их соединений выполняется
через шлейф с выходами (см. раздел 4.5.2).
