# 3.3.4. Регистр IrDA UARTILPR

`UARTILPR` — 8-битный регистр чтения/записи, хранящий делитель для
формирования сигнала `IrLPBaud16` из `UARTCLK`. Сигнал используется
блоком IrDA в режиме низкого потребления.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x020` |
| Тип | RW |
| Ширина | 8 бит |
| Значение после сброса | `0x00` |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 7:0 | `ILPDVSR` | 8-битное значение делителя низкого потребления |

## Формула

```text
IrLPBaud16 = UARTCLK / ILPDVSR
```

или, что то же самое:

```text
ILPDVSR = UARTCLK / IrLPBaud16
```

Номинальная частота `IrLPBaud16` — 1,8432 МГц.

## Допустимый диапазон

Делитель нужно выбирать так, чтобы частота попадала в диапазон:

```text
1,42 МГц < IrLPBaud16 < 2,12 МГц
```

Это соответствует длительности импульса от 1,41 до 2,11 мкс (три периода
`IrLPBaud16`). Минимальная частота нужна, чтобы декодер отбрасывал
импульсы короче одного периода `UARTCLK` как помеху, а импульсы длиннее
двух периодов принимал как достоверные.

## Нулевое значение недопустимо

Если записать `ILPDVSR = 0`, сигнал `IrLPBaud16` не формируется вовсе,
и режим низкого потребления IrDA работать не будет. Это не ошибка
шины — просто импульсы не вырабатываются.

## Пример

При `UARTCLK = 14,7456 МГц`:

```text
ILPDVSR = 14 745 600 / 1 843 200 = 8
```

Записываем `8` в `UARTILPR`. Получаем `IrLPBaud16 = 1,8432 МГц` —
ровно номинальное значение.

## Когда регистр не нужен

Если режим низкого потребления не используется (`SIRLP = 0`), делитель
не влияет на работу: импульсы формируются с длительностью 3/16 битового
интервала. Регистр всё равно можно запрограммировать заранее — это
позволит переключать режим без перенастройки.

При выключенном блоке IrDA (`SIREN = 0`) регистр не оказывает влияния
на контроллер.
