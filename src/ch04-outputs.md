# 4.6. Тестирование выходов

Интеграционное тестирование выходов проверяет, что внутренние
сигналы доходят до выводов и до потребителей внутри системы.
Проверка делится на две части:

- внутрикристальные выходы;
- первичные выходы (выводы кристалла).

## Общий принцип

Для выходов используется управление: значение задаётся через
`UARTITOP`, а затем читается либо обратно из того же регистра,
либо со стороны принимающего устройства.

| Группа | Биты `UARTITOP` | Способ проверки |
|--------|-----------------|-----------------|
| Внутрикристальные | 15:6 | Запись и чтение через `UARTITOP` |
| Первичные | 5:0 | Шлейф на входы и чтение через `UARTITIP` |

## Порядок

```text
1. Установить ITEN = 1 в UARTTCR.
2. Подать значения в нужные биты UARTITOP.
3. Для внутрикристальных — прочитать UARTITOP.
4. Для первичных — прочитать соответствующие биты UARTITIP.
5. Снять ITEN.
```

## Отличие от теста входов

При тесте входов значение приходит извне и наблюдается внутри.
При тесте выходов значение задаётся внутри и наблюдается снаружи.
В обоих случаях проверяется целостность пути сигнала.
