# A.3. Сигналы выводов

Сигналы этого раздела выходят на контактные площадки кристалла.
При интеграции необходимо правильно использовать выводы, чтобы
выполнить требования интерфейса.

## Таблица сигналов

| Имя | Тип | Тип вывода | Описание |
|-----|-----|------------|----------|
| `nUARTCTS` | Вход | PAD | Вход состояния модема Clear To Send, активный низкий; читается в `UARTFR` |
| `nUARTDCD` | Вход | PAD | Вход Data Carrier Detect, активный низкий; читается в `UARTFR` |
| `nUARTDSR` | Вход | PAD | Вход Data Set Ready, активный низкий; читается в `UARTFR` |
| `nUARTRI` | Вход | PAD | Вход Ring Indicator, активный низкий; читается в `UARTFR` |
| `UARTRXD` | Вход | PAD | Вход последовательных данных |
| `SIRIN` | Вход | PAD | Вход последовательных данных SIR |
| `UARTTXD` | Выход | PAD | Выход последовательных данных; после сброса находится в состоянии маркера (1) |
| `nSIROUT` | Выход | PAD | Выход последовательных данных SIR, активный низкий |
| `nUARTDTR` | Выход | PAD | Выход Data Terminal Ready, активный низкий; после сброса 0 |
| `nUARTRTS` | Выход | PAD | Выход Request To Send, активный низкий; после сброса 0 |
| `nUARTOut1` | Выход | PAD | Выход Out1, активный низкий; после сброса 0 |
| `nUARTOut2` | Выход | PAD | Выход Out2, активный низкий; после сброса 0 |

## Линия SIRIN

В состоянии покоя линия находится в состоянии маркера, то есть 1.
Когда принимается световой импульс, представляющий логический 0,
сигнал становится равен 0.

## Линия nSIROUT

В состоянии покоя сигнал равен 0 — это состояние маркера. Когда
сигнал устанавливается в 1, формируется инфракрасный импульс,
представляющий логический 0 в линии (состояние пробела).

Обратите внимание: полярность `nSIROUT` противоположна полярности
`SIRIN`. Это не ошибка, а следствие того, что световой импульс
соответствует активному низкому уровню на входе приёмника.

## Уровни после сброса

| Сигнал | После сброса |
|--------|--------------|
| `UARTTXD` | 1 (маркер) |
| `nSIROUT` | 0 (маркер) |
| `nUARTDTR` | 0 (активный) |
| `nUARTRTS` | 0 (активный) |
| `nUARTOut1` | 0 (активный) |
| `nUARTOut2` | 0 (активный) |

## Замечание о выходах модема

Все модемные выходы после сброса находятся в активном состоянии
(низкий уровень). Это соответствует рекомендации стандарта RS-232:
терминал после сброса сообщает о своей готовности. Если такое
поведение нежелательно, программное обеспечение должно снять
соответствующие биты в `UARTCR` при инициализации.
