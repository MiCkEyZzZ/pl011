# 3.3.1. Регистр данных UARTDR

`UARTDR` — регистр данных. Через него выполняется и передача, и приём:
запись помещает символ в передающий FIFO, чтение извлекает символ
из принимающего FIFO вместе с признаками ошибок.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x000` |
| Тип | RW |
| Ширина | 12 бит при чтении, 8 бит при записи |
| Значение после сброса | Не определено |

## Битовые поля

| Биты | Имя | Тип | Описание |
|------|-----|-----|----------|
| 15:12 | — | — | Зарезервировано |
| 11 | `OE` | RO | Переполнение принимающего FIFO |
| 10 | `BE` | RO | Обрыв линии |
| 9 | `PE` | RO | Ошибка чётности |
| 8 | `FE` | RO | Ошибка кадра |
| 7:0 | `DATA` | RW | Символ: чтение — принятый, запись — передаваемый |

## Передача

Запись в `UARTDR` помещает байт в передающий FIFO, если FIFO включён,
или в удерживающий регистр, если FIFO выключен. Запись одновременно
запускает передачу. Символ дополняется стартовым битом, битом чётности
(если разрешён) и стоп-битами.

Если FIFO полон, запись игнорируется, а в `UARTFR` установлен `TXFF`.

## Приём

Чтение `UARTDR` извлекает из принимающего FIFO очередной символ.
В битах `[7:0]` возвращается байт данных, в битах `[11:8]` — признаки
ошибок, относящиеся именно к этому символу.

| Бит | Признак | Что означает |
|-----|---------|--------------|
| 11 | `OE` | Символ пришёл при полном FIFO и был потерян |
| 10 | `BE` | Линия удерживалась в нуле дольше полного кадра |
| 9 | `PE` | Чётность принятого символа не совпала с заданной |
| 8 | `FE` | В позиции стоп-бита оказался ноль |

Если FIFO пуст, установлен `RXFE`, а чтение возвращает неопределённое
значение.

## Альтернативное чтение статуса

Те же признаки можно прочитать из `UARTRSR`. Но сделать это нужно
**после** чтения `UARTDR`: регистр статуса обновляется только при чтении
данных и относится к последнему прочитанному символу.

## Пример

```c
/* Принять символ и проверить ошибки */
uint32_t v = *(volatile uint32_t *)(UART_BASE + 0x000);
uint8_t  data = v & 0xFF;
if (v & (1u << 11)) { /* overrun */ }
if (v & (1u << 10)) { /* break   */ }
if (v & (1u <<  9)) { /* parity  */ }
if (v & (1u <<  8)) { /* framing */ }
```

## Предупреждение

Перед перепрограммированием управляющих регистров UART нужно выключить.
Если выключить UART посреди передачи или приёма, контроллер завершит
текущий символ и только затем остановится.
