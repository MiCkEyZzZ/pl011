# 3.2. Сводка регистров

В таблице приведены все программно-доступные регистры контроллера.
Смещения указаны относительно базового адреса блока.

| Смещение | Имя | Тип | Ширина | Сброс | Назначение |
|----------|-----|-----|--------|-------|------------|
| `0x000` | `UARTDR` | RW | 12/8 | — | Данные (чтение — 12 бит, запись — 8) |
| `0x004` | `UARTRSR`/`UARTECR` | RW | 4/0 | `0x0` | Статус приёма / сброс ошибок |
| `0x018` | `UARTFR` | RO | 9 | `0b-10010---` | Флаги |
| `0x020` | `UARTILPR` | RW | 8 | `0x00` | Делитель IrDA низкого потребления |
| `0x024` | `UARTIBRD` | RW | 16 | `0x0000` | Целый делитель скорости |
| `0x028` | `UARTFBRD` | RW | 6 | `0x00` | Дробный делитель скорости |
| `0x02C` | `UARTLCR_H` | RW | 8 | `0x00` | Управление линией |
| `0x030` | `UARTCR` | RW | 16 | `0x0300` | Управление |
| `0x034` | `UARTIFLS` | RW | 6 | `0x12` | Уровни срабатывания FIFO |
| `0x038` | `UARTIMSC` | RW | 11 | `0x000` | Маска прерываний |
| `0x03C` | `UARTRIS` | RO | 11 | `0x00-` | Сырой статус прерываний |
| `0x040` | `UARTMIS` | RO | 11 | `0x00-` | Маскированный статус прерываний |
| `0x044` | `UARTICR` | WO | 11 | — | Сброс прерываний |
| `0x048` | `UARTDMACR` | RW | 3 | `0x00` | Управление DMA |
| `0x080` | `UARTTCR` | RW | 3 | `0x0` | Управление тестом |
| `0x084` | `UARTITIP` | RW | 8 | `0x00` | Тестовые входы |
| `0x088` | `UARTITOP` | RW | 14 | `0x000` | Тестовые выходы |
| `0x08C` | `UARTTDR` | RW | 11 | — | Тестовые данные |
| `0xFE0` | `UARTPeriphID0` | RO | 8 | `0x11` | Идентификация периферии, байт 0 |
| `0xFE4` | `UARTPeriphID1` | RO | 8 | `0x10` | Идентификация периферии, байт 1 |
| `0xFE8` | `UARTPeriphID2` | RO | 8 | `0x14` | Идентификация периферии, байт 2 |
| `0xFEC` | `UARTPeriphID3` | RO | 8 | `0x00` | Идентификация периферии, байт 3 |
| `0xFF0` | `UARTPCellID0` | RO | 8 | `0x0D` | Идентификация PrimeCell, байт 0 |
| `0xFF4` | `UARTPCellID1` | RO | 8 | `0xF0` | Идентификация PrimeCell, байт 1 |
| `0xFF8` | `UARTPCellID2` | RO | 8 | `0x05` | Идентификация PrimeCell, байт 2 |
| `0xFFC` | `UARTPCellID3` | RO | 8 | `0xB1` | Идентификация PrimeCell, байт 3 |

## Пояснения

**Ширина.** Указана ширина используемой части регистра. Например,
`UARTCR` занимает 16 бит, хотя расположен в 32-битном слове.

**`UARTDR`.** При чтении возвращаются 12 бит: 8 данных и 4 признака
ошибок. При записи используются только младшие 8 бит.

**`UARTRSR`/`UARTECR`.** Один и тот же адрес: чтение даёт статус приёма,
запись сбрасывает ошибки. Поэтому ширина указана как «4/0».

**Сброс `UARTCR = 0x0300`.** После сброса установлены биты `TXE` и `RXE`,
но сам UART выключен (`UARTEN = 0`).

**Сброс `UARTIFLS = 0x12`.** Пороги приёма и передачи установлены
на половину заполнения FIFO.

**Сброс `UARTFR`.** Биты `TXFE` и `RXFE` равны 1, остальные нули;
прочерки означают, что положение некоторых бит зависит от состояния
модемных входов.

**Сброс `UARTRIS`/`UARTMIS`.** Модемные биты `[3:0]` после сброса
не определены.

## Карта адресов

```text
base + 0x000  UARTDR          ┐
base + 0x004  UARTRSR/ECR     │
base + 0x018  UARTFR          │ общие регистры
base + 0x020  UARTILPR        │
base + 0x024  UARTIBRD        │
base + 0x028  UARTFBRD        │
base + 0x02C  UARTLCR_H       │
base + 0x030  UARTCR          │
base + 0x034  UARTIFLS        │
base + 0x038  UARTIMSC        │
base + 0x03C  UARTRIS         │
base + 0x040  UARTMIS         │
base + 0x044  UARTICR         │
base + 0x048  UARTDMACR       ┘
base + 0x080  UARTTCR         ┐
base + 0x084  UARTITIP        │ тестовые регистры
base + 0x088  UARTITOP        │
base + 0x08C  UARTTDR         ┘
base + 0xFE0  UARTPeriphID0   ┐
base + 0xFE4  UARTPeriphID1   │ идентификация периферии
base + 0xFE8  UARTPeriphID2   │
base + 0xFEC  UARTPeriphID3   ┘
base + 0xFF0  UARTPCellID0    ┐
base + 0xFF4  UARTPCellID1    │ идентификация PrimeCell
base + 0xFF8  UARTPCellID2    │
base + 0xFFC  UARTPCellID3    ┘
```
