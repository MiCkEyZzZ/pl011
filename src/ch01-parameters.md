# 1.1.2. Программируемые параметры

Поведение контроллера настраивается программно. Ниже перечислены параметры
и регистры, которыми они задаются.

## Параметры передачи

| Параметр | Регистр | Допустимые значения |
|----------|---------|---------------------|
| Скорость передачи | `UARTIBRD`, `UARTFBRD` | Целый делитель 0–65535, дробный 0–63 |
| Длина слова | `UARTLCR_H[6:5]` | 5, 6, 7 или 8 бит |
| Чётность | `UARTLCR_H[3:1]` | Нет, чётная, нечётная, фиксированная 1, фиксированная 0 |
| Стоп-биты | `UARTLCR_H[7]` | 1 или 2 |
| Разрешение FIFO | `UARTLCR_H[4]` | Включено или выключено |
| Обрыв передачи | `UARTLCR_H[0]` | Формирование break |

## Параметры приёма и прерываний

| Параметр | Регистр | Допустимые значения |
|----------|---------|---------------------|
| Уровень срабатывания приёмного FIFO | `UARTIFLS[5:3]` | 1/8, 1/4, 1/2, 3/4, 7/8 заполнения |
| Уровень срабатывания передающего FIFO | `UARTIFLS[2:0]` | 1/8, 1/4, 1/2, 3/4, 7/8 заполнения |
| Маска прерываний | `UARTIMSC` | По одному биту на источник |
| Сброс прерываний | `UARTICR` | По одному биту на источник |

## Управление

| Параметр | Регистр | Значение |
|----------|---------|----------|
| Разрешение UART | `UARTCR[0]` | 1 — включён |
| Разрешение передачи | `UARTCR[8]` | 1 — передатчик активен |
| Разрешение приёма | `UARTCR[9]` | 1 — приёмник активен |
| Режим петли | `UARTCR[7]` | 1 — выходы замкнуты на входы |
| Управление RTS | `UARTCR[11]` | Ручное или автоматическое |
| Управление DTR | `UARTCR[10]` | Ручное |
| Выходы Out1, Out2 | `UARTCR[13:12]` | Ручное |

## DMA

| Параметр | Регистр | Значение |
|----------|---------|----------|
| Разрешение DMA для приёма | `UARTDMACR[0]` | 1 — включено |
| Разрешение DMA для передачи | `UARTDMACR[1]` | 1 — включено |
| Размер пакета DMA | `UARTDMACR[5:4]` | 1, 4, 8, 16 слов |

## IrDA

| Параметр | Регистр | Значение |
|----------|---------|----------|
| Делитель низкопотребляющего режима | `UARTILPR[7:0]` | 0–255 |
| Выбор режима IrDA | `UARTCR[1]` | 1 — IrDA SIR |
| Модуляция 3/16 | `UARTCR[?]`/`UARTILPR` | По конфигурации |

## Значения после сброса

После сброса все регистры обнулены: UART выключен, FIFO отключены, скорость
не задана, прерывания замаскированы. Программное обеспечение должно
настроить контроллер перед использованием.
