# 3.3. Описание регистров

В этом разделе описан каждый регистр контроллера: назначение, битовые
поля и правила доступа. Тестовые регистры описаны отдельно в главе 4.

## Порядок изложения

| Раздел | Регистр |
|--------|---------|
| 3.3.1 | `UARTDR` — данные |
| 3.3.2 | `UARTRSR`/`UARTECR` — статус приёма и сброс ошибок |
| 3.3.3 | `UARTFR` — флаги |
| 3.3.4 | `UARTILPR` — делитель IrDA |
| 3.3.5 | `UARTIBRD` — целый делитель |
| 3.3.6 | `UARTFBRD` — дробный делитель |
| 3.3.7 | `UARTLCR_H` — управление линией |
| 3.3.8 | `UARTCR` — управление |
| 3.3.9 | `UARTIFLS` — уровни FIFO |
| 3.3.10 | `UARTIMSC` — маска прерываний |
| 3.3.11 | `UARTRIS` — сырой статус |
| 3.3.12 | `UARTMIS` — маскированный статус |
| 3.3.13 | `UARTICR` — сброс прерываний |

## Общая схема описания

Для каждого регистра указаны:

- смещение относительно базового адреса;
- тип доступа (RO, WO, RW);
- ширина используемой части;
- значение после сброса;
- таблица битовых полей.

## Соглашения о значениях

| Обозначение | Смысл |
|-------------|-------|
| `x` | Значение не важно |
| `-` | Поле отсутствует или зарезервировано |
| DNM | Do Not Modify: изменять нельзя |
| «читается как ноль» | При чтении возвращается 0 |

## Важное предупреждение

Перед изменением управляющих регистров UART нужно выключить:

```text
1. UARTEN = 0
2. дождаться завершения текущего символа
3. при необходимости очистить FIFO (FEN = 0)
4. запрограммировать регистры
5. включить UART снова
```

Нарушение этого порядка — частая причина «необъяснимых» ошибок приёма
и передачи.
