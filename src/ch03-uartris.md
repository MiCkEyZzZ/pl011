# 3.3.11. Сырой статус прерываний UARTRIS

`UARTRIS` — регистр только для чтения, содержащий состояние каждого
источника прерывания до применения маски.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x03C` |
| Тип | RO |
| Ширина | 11 бит |
| Значение после сброса | `0x00−` |

## Битовые поля

| Бит | Имя | Источник |
|-----|-----|----------|
| 15:11 | — | Зарезервировано |
| 10 | `OERIS` | Ошибка переполнения |
| 9 | `BERIS` | Обрыв |
| 8 | `PERIS` | Ошибка чётности |
| 7 | `FERIS` | Ошибка кадра |
| 6 | `RTRIS` | Тайм-аут приёма |
| 5 | `TXRIS` | Передающий FIFO дошёл до порога |
| 4 | `RXRIS` | Принимающий FIFO дошёл до порога |
| 3 | `DSRRMIS` | Изменение `nUARTDSR` |
| 2 | `DCDRMIS` | Изменение `nUARTDCD` |
| 1 | `CTSRMIS` | Изменение `nUARTCTS` |
| 0 | `RIRMIS` | Изменение `nUARTRI` |

## Запись

Запись не оказывает никакого действия. Сброс флагов выполняется через
`UARTICR` (см. раздел 3.3.13).

## Особенность сброса

Биты `[15:4]` после сброса равны нулю. Модемные биты `[3:0]` после
сброса **не определены**: их состояние зависит от уровней на входах
в момент снятия сброса.

## Тайм-аут приёма

Для бита `RTRIS` действует особое правило: он не может установиться,
пока не установлена маска `RTIM` в `UARTIMSC`. Маска здесь работает
как разрешение питания. Поэтому для тайм-аута значения `UARTRIS`
и `UARTMIS` совпадают.

## Применение

`UARTRIS` полезен, когда нужно узнать о событии, даже если прерывание
по нему замаскировано. Например, можно опрашивать `UARTRIS[4]`
вместо прерывания приёма или проверять, не было ли ошибки, не разрешая
`UARTEINTR`.

```c
uint32_t ris = *(volatile uint32_t *)(UART_BASE + 0x03C);

if (ris & (1u << 10)) { /* переполнение */ }
if (ris & (1u << 6))  { /* тайм-аут приёма */ }
```

## Связь с UARTMIS

```text
UARTMIS = UARTRIS AND UARTIMSC
```

`UARTRIS` показывает, что произошло; `UARTMIS` — что из этого реально
выдаётся на линию прерывания.
