# 3.3.8. Регистр управления UARTCR

`UARTCR` — главный регистр управления. Он включает UART, передатчик
и приёмник, управляет модемными выходами, режимом петли и блоком IrDA.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x030` |
| Тип | RW |
| Ширина | 16 бит |
| Значение после сброса | `0x0300` |

После сброса установлены только биты 9 (`RXE`) и 8 (`TXE`); сам UART
выключен (`UARTEN = 0`).

## Битовые поля

| Бит | Имя | Описание |
|-----|-----|----------|
| 15 | `CTSEn` | Аппаратное управление потоком по CTS |
| 14 | `RTSEn` | Аппаратное управление потоком по RTS |
| 13 | `Out2` | Инвертированный выход `nUARTOut2` |
| 12 | `Out1` | Инвертированный выход `nUARTOut1` |
| 11 | `RTS` | Инвертированный выход `nUARTRTS` |
| 10 | `DTR` | Инвертированный выход `nUARTDTR` |
| 9 | `RXE` | Разрешение приёма |
| 8 | `TXE` | Разрешение передачи |
| 7 | `LBE` | Режим петли |
| 6:3 | — | Зарезервировано, читается как ноль |
| 2 | `SIRLP` | Режим низкого потребления IrDA |
| 1 | `SIREN` | Включение блока IrDA SIR |
| 0 | `UARTEN` | Включение UART |

## Включение

Для передачи нужны **оба** бита: `UARTEN` и `TXE`. Для приёма — `UARTEN`
и `RXE`. Один `UARTEN` без `TXE`/`RXE` не включает обмен.

Если выключить UART посреди передачи или приёма, контроллер завершит
текущий символ и только затем остановится.

## Модемные выходы

Биты выходов инвертированы: запись 1 даёт низкий уровень на выводе,
что означает активное состояние сигнала.

| Бит | Программное значение | Уровень на выводе |
|-----|----------------------|-------------------|
| `RTS` | 1 | 0 (активен) |
| `DTR` | 1 | 0 (активен) |
| `Out1` | 1 | 0 |
| `Out2` | 1 | 0 |

## Режим петли

При `LBE = 1` выход передающей логики замыкается на вход принимающей,
а модемные выходы — на модемные входы. Это позволяет проверить тракт
без внешнего оборудования.

Особый случай — петля через блок IrDA. Она требует одновременно:

```text
LBE = 1
SIREN = 1
SIRTEST = 1   (UARTTCR[2])
```

В этом состоянии путь `nSIROUT` инвертируется и подаётся на `SIRIN`.
После теста `SIRTEST` нужно сбросить, иначе нормальная полудуплексная
работа IrDA будет нарушена.

## IrDA

| Бит | Действие |
|-----|----------|
| `SIREN = 1` | Данные идут через `nSIROUT`/`SIRIN` |
| `SIRLP = 0` | Импульс длиной 3/16 битового интервала |
| `SIRLP = 1` | Импульс длиной 3 периода `IrLPBaud16` |

`SIREN` не действует, если UART выключен.

## Порядок программирования

```text
1. Выключить UART (UARTEN = 0).
2. Дождаться конца текущего символа.
3. Очистить передающий FIFO (FEN = 0).
4. Запрограммировать UARTCR.
5. Включить UART.
```

Нарушение порядка — частая причина «зависания» передачи.

## Пример

```c
#define UART_CR       (UART_BASE + 0x030)
#define CR_UARTEN     (1u << 0)
#define CR_TXE        (1u << 8)
#define CR_RXE        (1u << 9)

*(volatile uint32_t *)UART_CR = CR_UARTEN | CR_TXE | CR_RXE;
```
