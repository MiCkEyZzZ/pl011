# 3.3.15. Идентификация периферии UARTPeriphID0-3

Четыре 8-битных регистра в диапазоне `0xFE0`–`0xFEC` содержат постоянную
информацию о компоненте. Вместе они образуют 32-битный идентификатор
периферии.

## Расположение

| Регистр | Смещение | Значение |
|---------|----------|----------|
| `UARTPeriphID0` | `0xFE0` | `0x11` |
| `UARTPeriphID1` | `0xFE4` | `0x10` |
| `UARTPeriphID2` | `0xFE8` | `0x14` |
| `UARTPeriphID3` | `0xFEC` | `0x00` |

Составное 32-битное значение — `0x00141011`.

## Поля идентификатора

| Поле | Биты слова | Значение для PL011 |
|------|------------|--------------------|
| `PartNumber[11:0]` | `[11:0]` | `0x011` |
| `Designer ID[19:12]` | `[19:12]` | `0x41` (ASCII `A`, ARM Limited) |
| `Revision[23:20]` | `[23:20]` | Номер ревизии компонента |
| `Configuration[31:24]` | `[31:24]` | `0x00` |

## Разбивка по регистрам

| Регистр | Биты регистра | Поле |
|---------|---------------|------|
| `UARTPeriphID0` | `[7:0]` | `PartNumber0` = `0x11` |
| `UARTPeriphID1` | `[7:4]` | `Designer0` = `0x1` |
| `UARTPeriphID1` | `[3:0]` | `PartNumber1` = `0x0` |
| `UARTPeriphID2` | `[7:4]` | `Revision` |
| `UARTPeriphID2` | `[3:0]` | `Designer1` = `0x4` |
| `UARTPeriphID3` | `[7:0]` | `Configuration` = `0x00` |

## Замечание о номере ревизии

В оригинальном руководстве есть расхождение: сводная таблица регистров
приводит для `UARTPeriphID2` значение `0x14`, а детальное описание поля
`Revision` — значение `0x3` (что дало бы `0x34`). Для стандартного
ARM PL011, интегрированного в большинство SoC, читается `0x14`,
то есть ревизия 1. Надёжнее сверять всё слово целиком с `0x00141011`,
а не полагаться на один байт.

## Назначение

Регистры позволяют программному обеспечению убедиться, что по указанному
адресу находится именно PL011. Это полезно при автоматическом
обнаружении периферии и при проверке совместимости.

Запись в регистры игнорируется: значения жёстко заданы в кремнии.

## Пример проверки

```c
static int pl011_present(void)
{
    uint32_t id = 0;

    for (int i = 0; i < 4; i++)
        id |= (*(volatile uint32_t *)(UART_BASE + 0xFE0 + 4 * i) & 0xFF)
              << (8 * i);

    return id == 0x00141011;
}
```

## Замечание о разрядности

Регистры 8-битные, но расположены в 32-битных словах. Старшие биты
слова при чтении не определены, поэтому при сравнении нужно маскировать
младший байт. Обращения должны быть 32-битными (`LDR`/`STR`).
