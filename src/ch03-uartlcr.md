# 3.3.7. Регистр управления линией UARTLCR_H

`UARTLCR_H` — регистр управления линией. Он задаёт формат кадра, режим
FIFO и формирование обрыва.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x02C` |
| Тип | RW |
| Ширина | 8 бит |
| Значение после сброса | `0x00` |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 15:8 | — | Зарезервировано, читается как ноль |
| 7 | `SPS` | Фиксированная чётность |
| 6:5 | `WLEN` | Длина слова: `11` — 8, `10` — 7, `01` — 6, `00` — 5 бит |
| 4 | `FEN` | Включение FIFO |
| 3 | `STP2` | Два стоп-бита |
| 2 | `EPS` | Чётная чётность |
| 1 | `PEN` | Разрешение чётности |
| 0 | `BRK` | Формирование обрыва |

## Длина слова

| `WLEN` | Битов данных |
|--------|--------------|
| `00` | 5 |
| `01` | 6 |
| `10` | 7 |
| `11` | 8 |

Младший бит передаётся первым.

## Чётность

| `PEN` | `EPS` | `SPS` | Что передаётся и проверяется |
|-------|-------|-------|------------------------------|
| 0 | x | x | Чётность отсутствует |
| 1 | 1 | 0 | Чётная чётность |
| 1 | 0 | 0 | Нечётная чётность |
| 1 | 0 | 1 | Фиксированная единица |
| 1 | 1 | 1 | Фиксированный ноль |

Фиксированная чётность полезна для проверки связи: значение бита
чётности известно заранее и не зависит от данных.

## Стоп-биты

`STP2 = 0` — один стоп-бит, `STP2 = 1` — два. Приёмник проверяет только
первый стоп-бит; второй не контролируется.

## FIFO

`FEN = 1` включает FIFO глубиной 16 символов. `FEN = 0` превращает
их в удерживающие регистры глубиной 1 символ. Очистка FIFO выполняется
переходом `FEN` из 1 в 0 — содержимое при этом теряется.

## Обрыв

`BRK = 1` заставляет передающую логику удерживать линию в нуле после
завершения текущего символа. Для надёжного распознавания приёмником
бит нужно удерживать не менее двух полных кадров. В обычной работе
бит должен быть равен нулю.

## Связь с делителями

`UARTLCR_H`, `UARTIBRD` и `UARTFBRD` образуют единый внутренний 30-битный
регистр `UARTLCR`. Он обновляется по стробирующему сигналу, который
формируется записью в `UARTLCR_H`. Поэтому запись в `UARTLCR_H` нужна
всегда, когда требуется применить новые значения делителей.

## Ограничения

- Нельзя менять скорость и формат кадра при включённом UART.
- Нельзя менять их во время передачи или приёма.
- Целостность FIFO не гарантируется, если инициирован обрыв или если
  UART выключили посреди передачи с данными в FIFO, а затем включили
  снова.

## Пример

```c
/* 8 бит, без чётности, 1 стоп-бит, FIFO включён */
*(volatile uint32_t *)(UART_BASE + 0x02C) = (3u << 5) | (1u << 4);
```
