# 2.5. Работа модемных сигналов

Помимо линий данных `TXD` и `RXD`, контроллер имеет четыре модемных входа
и четыре модемных выхода. Они позволяют подключать внешний модем или
управлять дополнительными цепями.

## Сигналы

| Сигнал | Направление | Назначение |
|--------|-------------|------------|
| `nUARTCTS` | вход | Clear To Send: модем готов принимать |
| `nUARTDSR` | вход | Data Set Ready: модем готов к работе |
| `nUARTDCD` | вход | Data Carrier Detect: обнаружена несущая |
| `nUARTRI` | вход | Ring Indicator: входящий звонок |
| `nUARTRTS` | выход | Request To Send: терминал готов принимать |
| `nUARTDTR` | выход | Data Terminal Ready: терминал готов к работе |
| `nUARTOut1` | выход | Дополнительный выход (обычно DCD у DTE) |
| `nUARTOut2` | выход | Дополнительный выход (обычно RI у DTE) |

Все сигналы активны низким уровнем, поэтому имена начинаются с `n`.

## Инверсия выходов

Управляющие биты выходов инвертированы:

| Бит `UARTCR` | Программное значение | Уровень на выводе |
|--------------|----------------------|-------------------|
| `RTS` (11) | 1 | 0 (активен) |
| `DTR` (10) | 1 | 0 (активен) |
| `Out1` (12) | 1 | 0 |
| `Out2` (13) | 1 | 0 |

Это соответствует логике «записать 1, чтобы включить сигнал», хотя
физически на выводе будет ноль.

## Входы и их отражение в регистрах

Состояние входов отражается в `UARTFR` в инвертированном виде:

| Бит `UARTFR` | Сигнал | Значение 1 означает |
|--------------|--------|---------------------|
| 0 | `CTS` | `nUARTCTS` = 0 (активен) |
| 1 | `DSR` | `nUARTDSR` = 0 (активен) |
| 2 | `DCD` | `nUARTDCD` = 0 (активен) |
| 8 | `RI` | `nUARTRI` = 0 (активен) |

## Прерывания по изменению

Каждый модемный вход может вызвать прерывание `UARTMSINTR` при изменении
уровня. Соответствующие биты находятся в младших разрядах регистров:

| Бит | Источник |
|-----|----------|
| 0 | `nUARTRI` |
| 1 | `nUARTCTS` |
| 2 | `nUARTDCD` |
| 3 | `nUARTDSR` |

Прерывание устанавливается по фронту, а не по уровню, поэтому оно
не будет повторяться, пока сигнал не изменится снова.

## Фильтрация

Модемные входы проходят через синхронизатор и фильтр. Короткий импульс
помехи не фиксируется: изменение принимается только после того, как новый
уровень удержится в течение нескольких тактов. Это защищает от ложных
прерываний на длинных кабелях.

## Типичное применение

В простейшем случае (связь двух устройств без модема) модемные сигналы
не используются, а `nUARTCTS` и `nUARTDSR` подтягиваются к активному
уровню, чтобы передача не блокировалась аппаратным управлением потоком.
