# 2.7. Интерфейс DMA

Интерфейс DMA позволяет пересылать данные между FIFO контроллера
и памятью без участия процессора. Раздел дополняет описание блока
из п. 2.2.9 и посвящён практической стороне работы.

## Зачем нужен DMA

При передаче через прерывания процессор обслуживает каждый символ
или небольшую группу. На скорости 115200 бод символ приходит примерно
каждые 87 мкс — это заметная нагрузка. DMA перекладывает копирование
на отдельный контроллер, а процессор получает прерывание только
по завершении целого блока.

## Запросы UART

| Запрос | Направление | Условие |
|--------|-------------|---------|
| `UARTRXDMASREQ` | приём | Есть хотя бы один символ в FIFO |
| `UARTRXDMABREQ` | приём | Заполнение достигло порога |
| `UARTTXDMASREQ` | передача | Есть место хотя бы для одного символа |
| `UARTTXDMABREQ` | передача | Заполнение опустилось до порога |

Одиночный запрос удобен для передачи одного слова за раз, пакетный —
для пересылки нескольких слов подряд без повторного арбитража.

## Настройка

```c
/* Разрешить DMA для приёма и передачи, отключать приём при ошибке */
*(volatile uint32_t *)(UART_BASE + 0x048) = (1u << 0) | (1u << 1) | (1u << 2);
```

| Бит | Имя | Значение |
|-----|-----|----------|
| 0 | `RXDMAE` | Разрешение DMA приёма |
| 1 | `TXDMAE` | Разрешение DMA передачи |
| 2 | `DMAONERR` | Отключение приёма при ошибке |

## Порядок работы

1. Настроить UART: скорость, формат кадра, FIFO, прерывания.
2. Включить UART и передачу/приём.
3. Настроить контроллер DMA на нужный адрес `UARTDR` и длину блока.
4. Разрешить каналы в `UARTDMACR`.
5. По завершении запретить каналы.

## Взаимодействие с прерываниями

DMA и прерывания не исключают друг друга. Разумная схема:

- приём и передача данных — через DMA;
- ошибки (`OE`, `BE`, `PE`, `FE`) — через прерывание `UARTEINTR`;
- тайм-аут приёма — через `UARTRTINTR` для обработки «хвоста»,
  который не набрал полный пакет.

При `DMAONERR = 1` ошибка автоматически останавливает приёмный DMA,
и обработчик прерывания может разобраться в причине, не опасаясь,
что данные продолжают поступать.

## Ограничения

- DMA работает только с регистром `UARTDR`; остальные регистры
  настраиваются процессором.
- При выключенном FIFO пакетный режим неэффективен.
- Размер пакета задаётся настройками контроллера DMA, а не самим UART;
  UART лишь сообщает, когда в FIFO достаточно места или данных.
- При переполнении FIFO во время DMA часть данных может быть потеряна —
  поэтому приёмный DMA обычно настраивают так, чтобы он успевал
  опустошать FIFO быстрее, чем приходят символы.
