# 3.3.13. Регистр сброса прерываний UARTICR

`UARTICR` — регистр только для записи. Запись единицы в бит сбрасывает
соответствующий флаг прерывания в `UARTRIS`.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x044` |
| Тип | WO |
| Ширина | 11 бит |
| Значение после сброса | Не определено |

## Битовые поля

| Бит | Имя | Что сбрасывает |
|-----|-----|----------------|
| 15:11 | — | Зарезервировано |
| 10 | `OEIC` | Ошибка переполнения |
| 9 | `BEIC` | Обрыв |
| 8 | `PEIC` | Ошибка чётности |
| 7 | `FEIC` | Ошибка кадра |
| 6 | `RTIC` | Тайм-аут приёма |
| 5 | `TXIC` | Прерывание передачи |
| 4 | `RXIC` | Прерывание приёма |
| 3 | `DSRMIC` | Изменение `nUARTDSR` |
| 2 | `DCDMIC` | Изменение `nUARTDCD` |
| 1 | `CTSMIC` | Изменение `nUARTCTS` |
| 0 | `RIMIC` | Изменение `nUARTRI` |

## Запись

Запись единицы сбрасывает флаг; запись нуля не действует. Чтение
не имеет смысла: регистр только для записи.

```c
/* Сбросить все прерывания */
*(volatile uint32_t *)(UART_BASE + 0x044) = 0x7FF;

/* Сбросить только ошибки (биты 7–10) */
*(volatile uint32_t *)(UART_BASE + 0x044) = 0x780;
```

## Автоматический сброс

Некоторые флаги снимаются автоматически, без записи в `UARTICR`:

| Флаг | Когда снимается |
|------|-----------------|
| `RXIC` | FIFO опустел ниже порога |
| `TXIC` | FIFO заполнен выше порога |
| `RTIC` | FIFO стал пустым |

Остальные (ошибки и модемные изменения) требуют явной записи.

## Порядок в обработчике

```c
void uart_irq_handler(void)
{
    uint32_t mis = *(volatile uint32_t *)(UART_BASE + 0x040);

    if (mis & (1u << 4)) {
        while (!(*(volatile uint32_t *)(UART_BASE + 0x018) & (1u << 4)))
            (void)*(volatile uint32_t *)(UART_BASE + 0x000);
    }

    if (mis & 0x780)
        *(volatile uint32_t *)(UART_BASE + 0x044) = 0x780;
}
```

Сначала обрабатывается событие, затем сбрасывается флаг. Обратный
порядок может привести к потере информации о причине прерывания.

## Совет по инициализации

Перед разрешением прерываний полезно записать `0x7FF` в `UARTICR`:
это снимет устаревшие флаги, оставшиеся от предыдущей работы или
от момента снятия сброса (модемные биты после сброса не определены).
