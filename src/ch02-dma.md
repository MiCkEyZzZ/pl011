# 2.2.9. Интерфейс DMA

Интерфейс DMA позволяет контроллеру обмениваться данными с памятью
напрямую, без участия процессора. Это особенно полезно на высоких
скоростях передачи, когда обработка каждого символа прерыванием
становится накладной.

## Запросы

| Сигнал | Направление | Когда активен |
|--------|-------------|---------------|
| `UARTRXDMASREQ` | выход | В принимающем FIFO есть данные (одиночный запрос) |
| `UARTRXDMABREQ` | выход | Заполнение FIFO достигло порога (пакетный запрос) |
| `UARTTXDMASREQ` | выход | В передающем FIFO есть место (одиночный запрос) |
| `UARTTXDMABREQ` | выход | Заполнение FIFO опустилось до порога (пакетный запрос) |

Одиночный запрос означает «передай одно слово», пакетный — «передай
несколько слов подряд». Пороги определяются регистром `UARTIFLS` точно
так же, как для прерываний.

## Управление

| Бит | Имя | Назначение |
|-----|-----|------------|
| `UARTDMACR[0]` | `RXDMAE` | Разрешение DMA для приёма |
| `UARTDMACR[1]` | `TXDMAE` | Разрешение DMA для передачи |
| `UARTDMACR[2]` | `DMAONERR` | Отключать приёмный DMA при ошибке |

## Работа с ошибками

Если установлен `DMAONERR = 1`, то при возникновении прерывания ошибки
(`UARTEINTR`) приёмные запросы DMA отключаются. Это позволяет
контроллеру DMA остановиться и передать управление программному
обеспечению, которое разберётся с причиной ошибки.

При `DMAONERR = 0` приём продолжается даже при ошибках: признаки ошибок
попадают в FIFO вместе с данными, и программное обеспечение увидит
их позже.

## Типичная последовательность

```text
1. Настроить скорость, формат кадра, включить FIFO и UART.
2. Запрограммировать контроллер DMA:
   - источник/приёмник, длина, ширина слова;
   - режим (одиночный или пакетный).
3. Разрешить соответствующий канал в UARTDMACR.
4. Дождаться завершения пересылки.
5. Запретить канал в UARTDMACR.
```

## Особенности

- DMA не отменяет прерывания: их можно использовать одновременно,
  например для обработки ошибок при работающем DMA.
- Размер пакета и пороги задаются независимо для приёма и передачи.
- При выключенном FIFO (`FEN = 0`) пакетный режим теряет смысл: буфер
  вмещает один символ.
- Обращения DMA к `UARTDR` равносильны обращениям процессора: чтение
  извлекает символ, запись ставит его в очередь.
