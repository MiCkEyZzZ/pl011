# 2.4.5. Кадр символа UART

Асинхронный обмен не использует общий тактовый сигнал, поэтому каждая
передача обособлена: приёмник узнаёт о начале символа по стартовому биту,
а о конце — по стоп-битам.

## Структура кадра

```text
  ┌───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┐
  │ 0 │D0 │D1 │D2 │D3 │D4 │D5 │D6 │D7 │ P │ 1 │ 1 │
  └───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┘
   старт  данные (младший бит первым)  чёт  стоп-биты
```

| Элемент | Длина | Значение |
|---------|-------|----------|
| Стартовый бит | 1 | Всегда 0 |
| Данные | 5–8 | Младший бит первым |
| Чётность | 0 или 1 | Зависит от `PEN`, `EPS`, `SPS` |
| Стоп-биты | 1 или 2 | Всегда 1 |

## Примеры

**8 бит, без чётности, 1 стоп-бит** — самый распространённый режим
(«8N1»):

```text
0 D0 D1 D2 D3 D4 D5 D6 D7 1
```

**7 бит, чётная чётность, 1 стоп-бит** — типично для старых терминалов:

```text
0 D0 D1 D2 D3 D4 D5 D6 P 1
```

**8 бит, без чётности, 2 стоп-бита** («8N2»):

```text
0 D0 D1 D2 D3 D4 D5 D6 D7 1 1
```

## Длительность

Длительность одного бита равна `1 / Baud rate`. Полный кадр занимает:

```text
T = (1 старт + N данных + P чётность + S стоп) / Baud rate
```

Например, для 8N1 при 115200 бод:

```text
T = 10 / 115200 ≈ 86,8 мкс
```

## Синхронизация

Приёмник запускается по спаду стартового бита. Затем он отсчитывает
битовые интервалы и выбирает значения в их середине — так погрешность
скорости распределяется в обе стороны от точки выборки.

Если скорости сторон различаются, точка выборки постепенно смещается
от середины. Когда смещение превышает половину бита, символ принимается
неверно: появляется ошибка кадра (`FE`) или ошибка чётности (`PE`).

## Что не проверяется

Приёмник не проверяет второй стоп-бит: он лишь требует, чтобы
в позиции первого стоп-бита была единица. Поэтому кадр с двумя
стоп-битами может быть принят приёмником, настроенным на один.

## Настройка

| Параметр | Поле |
|----------|------|
| Длина слова | `UARTLCR_H[6:5]` |
| Чётность | `UARTLCR_H[3:1]` |
| Стоп-биты | `UARTLCR_H[7]` |

Менять эти поля можно только при выключенном UART.
