# 1.1.3. Отличия от UART 16C550

PL011 функционально близок к промышленному стандарту 16C550, но не является
его регистровым клоном. Ниже перечислены основные отличия.

## Карта регистров

| Аспект | 16C550 | PL011 |
|--------|--------|-------|
| Доступ к делителю | Через `DLL`/`DLM` при `DLAB = 1` | Отдельные регистры `UARTIBRD` и `UARTFBRD`, без `DLAB` |
| Регистр управления FIFO | `FCR` (только запись) | Отдельного нет: FIFO включается битом `UARTLCR_H[4]` |
| Уровни FIFO | `FCR[7:6]` | `UARTIFLS` |
| Идентификация прерывания | `IIR` | `UARTRIS`, `UARTMIS`, `UARTICR` |
| Управление модемом | `MCR` | `UARTCR` (совмещено с управлением UART) |
| Состояние линии | `LSR` | `UARTFR` + `UARTRSR` |

## Функциональные отличия

- **Дробный делитель.** PL011 имеет 6-битный дробный делитель, что позволяет
  точнее задавать скорость; у 16C550 делитель только целый.
- **Отдельные линии прерываний.** Помимо объединённого `UARTINTR`, PL011
  выводит пять отдельных линий по типам событий.
- **Тайм-аут приёма.** В PL011 он оформлен как отдельный источник
  прерывания `UARTRTINTR`.
- **Аппаратное управление потоком** встроено и настраивается битами
  `UARTCR`.
- **IrDA SIR** поддерживается аппаратно; у 16C550 его нет.
- **Интерфейс DMA** с отдельными запросами и программируемым размером
  пакета; у 16C550 подобного интерфейса нет.
- **Регистры идентификации PrimeCell** позволяют обнаружить устройство
  программно.

## Совместимость на уровне драйвера

Несмотря на различия, логика работы похожа: данные читаются и пишутся через
один регистр, состояние — через регистр флагов, прерывания маскируются
и сбрасываются отдельными регистрами. Драйвер, написанный для 16C550,
потребует переработки доступа к регистрам, но не изменения алгоритма.

## Чего нет в PL011

- Регистра `SCR` (scratch).
- Отдельного `FCR`: сброс FIFO выполняется через `UARTCR` и `UARTLCR_H`.
- Режима 1,5 стоп-бита.
- Автоматического определения скорости.

## Что есть в PL011 дополнительно

- Петля (loopback) для самопроверки.
- Раздельные запросы DMA на передачу и приём.
- Низкопотребляющий режим IrDA с программируемым делителем.
