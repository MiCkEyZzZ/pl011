# 3.3.5. Целый делитель UARTIBRD

`UARTIBRD` — 16-битный регистр чтения/записи, содержащий целую часть
делителя скорости передачи.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x024` |
| Тип | RW |
| Ширина | 16 бит |
| Значение после сброса | `0x0000` |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 15:0 | `BAUD DIVINT` | Целая часть делителя скорости |

## Формула

```text
BaudDIV = UARTCLK / (16 × Baud rate)
UARTIBRD = целая часть (BaudDIV)
UARTFBRD = round(дробная часть × 64)
```

## Ограничения

- `UARTIBRD = 0` недопустим: минимальный делитель равен 1, а `UARTFBRD`
  в этом случае игнорируется.
- Максимальное значение — `0xFFFF` (65535).
- Если `UARTIBRD = 0xFFFF`, то `UARTFBRD` должен быть равен нулю;
  иначе передача или приём прерываются.

## Когда применяется значение

Содержимое `UARTIBRD` и `UARTFBRD` не обновляется до завершения передачи
или приёма текущего символа. Кроме того, оба регистра образуют вместе
с `UARTLCR_H` единый внутренний регистр `UARTLCR`, который фиксируется
по записи в `UARTLCR_H`.

Поэтому после изменения делителя нужно выполнить запись в `UARTLCR_H`:

```text
UARTIBRD → UARTFBRD → UARTLCR_H
```

## Пример

При `UARTCLK = 4 МГц` и скорости 115200 бод:

```text
BaudDIV = 4 000 000 / (16 × 115 200) = 2,170
UARTIBRD = 2
UARTFBRD = round(0,170 × 64) = 11 (0x0B)
```

Результат: `UARTIBRD = 0x2`, `UARTFBRD = 0x0B`.

## Пример кода

```c
static void uart_set_baud(uint32_t uartclk, uint32_t baud)
{
    uint32_t div  = (uartclk * 4 + baud / 2) / baud;  /* ×4 для точности */
    uint32_t ibrd = div / 64;
    uint32_t fbrd = div % 64;

    *(volatile uint32_t *)(UART_BASE + 0x024) = ibrd;
    *(volatile uint32_t *)(UART_BASE + 0x028) = fbrd;
    *(volatile uint32_t *)(UART_BASE + 0x02C) |= 0;    /* применить */
}
```

Внимание: запись `0` в `UARTLCR_H` изменит формат кадра. В реальном
драйвере нужно прочитать текущее значение, записать его обратно
или заранее объединить настройку скорости и формата в одну запись.

## Ошибки

| Ситуация | Последствие |
|----------|-------------|
| `UARTIBRD = 0` | Скорость не определена, `UARTFBRD` игнорируется |
| `UARTIBRD = 0xFFFF` и `UARTFBRD ≠ 0` | Передача или приём прерываются |
| Изменение при включённом UART | Новое значение не применяется или применяется некорректно |
