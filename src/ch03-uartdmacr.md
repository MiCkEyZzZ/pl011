# 3.3.14. Управление DMA UARTDMACR

`UARTDMACR` — регистр чтения/записи, управляющий взаимодействием
с контроллером DMA.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x048` |
| Тип | RW |
| Ширина | 3 бита |
| Значение после сброса | `0x00` |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 15:3 | — | Зарезервировано, читается как ноль |
| 2 | `DMAONERR` | Отключать приёмный DMA при ошибке |
| 1 | `TXDMAE` | Разрешение DMA для передачи |
| 0 | `RXDMAE` | Разрешение DMA для приёма |

## Описание полей

**`RXDMAE`.** При установке в 1 контроллер выставляет запросы
`UARTRXDMASREQ` и `UARTRXDMABREQ` по мере поступления данных
в принимающий FIFO.

**`TXDMAE`.** При установке в 1 контроллер выставляет запросы
`UARTTXDMASREQ` и `UARTTXDMABREQ`, когда в передающем FIFO появляется
место.

**`DMAONERR`.** При установке в 1 приёмные запросы DMA отключаются,
как только возникает прерывание ошибки `UARTEINTR`. Это позволяет
контроллеру DMA остановиться, а программному обеспечению — разобраться
с причиной, не теряя поток данных бесконтрольно.

## Пример

```c
#define UART_DMACR     (UART_BASE + 0x048)
#define RXDMAE         (1u << 0)
#define TXDMAE         (1u << 1)
#define DMAONERR       (1u << 2)

/* Включить DMA приёма и передачи, останавливать приём при ошибке */
*(volatile uint32_t *)UART_DMACR = RXDMAE | TXDMAE | DMAONERR;
```

## Взаимодействие с прерываниями

DMA и прерывания работают одновременно:

- DMA пересылает данные;
- прерывания сообщают об ошибках и о завершении блока;
- тайм-аут приёма помогает дочитать «хвост», не набравший размер пакета.

## Отключение

Перед отключением DMA рекомендуется:

1. Дождаться завершения текущего пакета.
2. Снять `RXDMAE`/`TXDMAE`.
3. При необходимости обработать остаток FIFO вручную.

Резкое отключение во время пересылки может оставить часть данных
в FIFO необработанной.

## Ограничения

- Регистр не управляет самим контроллером DMA: адреса, длины и режимы
  задаются в его собственных регистрах.
- Ширина регистра — 3 бита; остальные биты зарезервированы и должны
  читаться как нули.
- При выключенном FIFO пакетный режим не даёт выигрыша.
