# 3.3.12. Маскированный статус UARTMIS

`UARTMIS` — регистр только для чтения, содержащий состояние прерываний
после применения маски. Именно эти значения определяют уровни
на выходах прерываний.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x040` |
| Тип | RO |
| Ширина | 11 бит |
| Значение после сброса | `0x00−` |

## Битовые поля

| Бит | Имя | Источник |
|-----|-----|----------|
| 15:11 | — | Зарезервировано |
| 10 | `OEMIS` | Ошибка переполнения |
| 9 | `BEMIS` | Обрыв |
| 8 | `PEMIS` | Ошибка чётности |
| 7 | `FEMIS` | Ошибка кадра |
| 6 | `RTMIS` | Тайм-аут приёма |
| 5 | `TXMIS` | Передающий FIFO дошёл до порога |
| 4 | `RXMIS` | Принимающий FIFO дошёл до порога |
| 3 | `DSRMMIS` | Изменение `nUARTDSR` |
| 2 | `DCDMMIS` | Изменение `nUARTDCD` |
| 1 | `CTSMMIS` | Изменение `nUARTCTS` |
| 0 | `RIMMIS` | Изменение `nUARTRI` |

## Вычисление

```text
UARTMIS = UARTRIS AND UARTIMSC
```

Бит установлен, только если событие произошло **и** прерывание
по нему разрешено.

## Связь с выходами

| Выход | Источник в `UARTMIS` |
|-------|----------------------|
| `UARTMSINTR` | `[3:0]` |
| `UARTRXINTR` | `[4]` |
| `UARTTXINTR` | `[5]` |
| `UARTRTINTR` | `[6]` |
| `UARTEINTR` | `[10:7]` |
| `UARTINTR` | сумма всех |

## Применение в обработчике

Чтение `UARTMIS` — стандартный первый шаг обработчика. Оно позволяет
определить источник, не выполняя отдельные чтения для каждой линии,
особенно если используется объединённое прерывание `UARTINTR`.

```c
void uart_irq_handler(void)
{
    uint32_t mis = *(volatile uint32_t *)(UART_BASE + 0x040);

    if (mis & (1u << 4)) {
        /* приём: читаем FIFO */
    }
    if (mis & (1u << 5)) {
        /* передача: можно писать в FIFO */
    }
    if (mis & (1u << 6)) {
        /* тайм-аут приёма: дочитать остаток */
    }
    if (mis & 0x780) {
        /* ошибки: разобраться и сбросить */
        *(volatile uint32_t *)(UART_BASE + 0x044) = 0x780;
    }
}
```

## Сброс

Регистр только для чтения. Чтобы снять бит, нужно сбросить
соответствующий флаг в `UARTRIS` записью в `UARTICR` либо устранить
причину события (например, опустошить FIFO).

## Особенность модемных битов

Как и в `UARTRIS`, модемные биты `[3:0]` после сброса не определены.
Перед разрешением модемных прерываний их стоит прочитать и при
необходимости сбросить через `UARTICR`.
