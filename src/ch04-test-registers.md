# 4.4. Описание тестовых регистров

В этом разделе описаны четыре тестовых регистра. Каждый из них
предназначен для своей задачи.

## Состав раздела

| Раздел | Регистр | Назначение |
|--------|---------|------------|
| 4.4.1 | `UARTTCR` | Управление режимом теста |
| 4.4.2 | `UARTITIP` | Входы интеграционного теста |
| 4.4.3 | `UARTITOP` | Выходы интеграционного теста |
| 4.4.4 | `UARTTDR` | Данные для обхода FIFO |

## Общие свойства

- Все регистры 32-битные по доступу; значащие биты занимают младшую
  часть слова.
- Старшие биты зарезервированы, при чтении не определены.
- Запись в зарезервированные биты не влияет на работу.
- Регистры доступны только в тестовом режиме; в обычной работе
  обращаться к ним не следует.

## Режимы

| Режим | Условие | Что доступно |
|-------|---------|--------------|
| Обычный | `UARTTCR[0] = 0` | Работа UART, тестовые функции выключены |
| Интеграционный тест | `UARTTCR[0] = 1` | Прямое управление входами и выходами |
| Обход FIFO | `UARTTCR[1] = 1` | `UARTTDR` пишет в приёмный FIFO и читает из передающего |
| Тест IrDA | `UARTTCR[2] = 1` | Приём работает во время передачи SIR |
