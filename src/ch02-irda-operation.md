# 2.4.4. Работа IrDA SIR

Режим IrDA SIR включается битом `SIREN` и работает поверх той же
передающей и принимающей логики, что и обычный UART.

## Включение

```text
1. Настроить скорость и формат кадра (UARTIBRD, UARTFBRD, UARTLCR_H).
2. Записать делитель IrLPBaud16 в UARTILPR (если нужен режим низкого
   потребления).
3. Установить SIREN = 1.
4. При необходимости установить SIRLP = 1.
5. Включить UART (UARTEN = 1), передачу (TXE) и приём (RXE).
```

Блок SIR не работает, если UART выключен битом `UARTEN`.

## Что меняется

Когда `SIREN = 1`:

| Сигнал | Поведение |
|--------|-----------|
| `TXD` | Остаётся в единице (в покое) |
| `RXD` | Игнорируется |
| `nSIROUT` | Выдаёт импульсы вместо нулевых битов |
| `SIRIN` | Принимает импульсы |
| Модемные входы | Игнорируются |

## Передача

Передающая логика формирует обычный кадр UART, но он не выводится
на `TXD`. Вместо этого кодер заменяет каждый нулевой бит импульсом
на `nSIROUT`. Единичные биты передаются отсутствием света.

## Приём

Декодер превращает импульсы с `SIRIN` обратно в поток нулей и единиц,
который обрабатывается принимающей логикой. Формат кадра и скорость
должны совпадать с передающей стороной.

## Полудуплекс

Поскольку инфракрасный канал обычно один, обмен идёт по очереди:
одно устройство передаёт, другое принимает. Протокол верхнего уровня
(например, IrLAP) определяет, когда можно переключать направление.
Контроллер сам направление не переключает.

## Режим петли

Для самопроверки используется сочетание:

```text
LBE = 1        (UARTCR[7])
SIREN = 1      (UARTCR[1])
SIRTEST = 1    (UARTTCR[2])
```

В этом состоянии путь `nSIROUT` инвертируется и подаётся на `SIRIN`:
переданный символ принимается обратно. После теста `SIRTEST` нужно
сбросить в ноль, иначе обычная полудуплексная работа будет нарушена.

## Отключение

При `SIREN = 0`:

- вывод `nSIROUT` удерживается в нуле, то есть светодиод выключен;
- переходы на `SIRIN` не влияют на приёмник;
- данные снова передаются и принимаются через `TXD`/`RXD`.
