# 3.4.3. UARTTXINTR

`UARTTXINTR` — прерывание передачи. Оно сообщает, что в передающем
FIFO появилось место для новых данных.

## Условия формирования

### FIFO включён

Прерывание выставляется, когда число символов в передающем FIFO
опускается до порога `TXIFLSEL` или ниже него. Снимается оно
записью данных в FIFO, пока уровень не поднимется выше порога,
либо записью единицы в бит `TXIC` регистра `UARTICR`.

### FIFO выключен

Глубина равна одному элементу. Прерывание выставляется, когда этот
элемент пуст, и снимается одной записью в `UARTDR` либо записью
в `UARTICR`.

## Важное замечание о переходе

Прерывание передачи построено на **переходе** через порог, а не на
самом уровне. Если разрешить прерывание и включить UART до записи
первых данных, прерывание не выставится. Оно возникнет только после
того, как записанный символ покинет FIFO и тот опустеет.

Практический вывод: первое слово в передающий FIFO нужно записать
явно, до или сразу после включения. Рассчитывать на стартовое
прерывание нельзя.

## Порядок обработки

```c
void uart_tx_isr(void)
{
    while (1) {
        uint32_t fr = *(volatile uint32_t *)(UART_BASE + 0x018);

        /* TFF (бит 5) — передающий FIFO заполнен */
        if (fr & (1u << 5))
            break;

        if (!tx_has_data())
            break;

        *(volatile uint32_t *)(UART_BASE + 0x000) = tx_pop();
    }
}
```

Если данные закончились, прерывание передачи лучше запретить:
иначе оно будет возникать постоянно, пока FIFO пуст.

## Взаимодействие с DMA

При включённом `TXDMAE` данные в FIFO подаёт контроллер DMA,
а прерывание используется для пополнения буфера описаниями
или для сигнала о завершении.

## Следствие для драйвера

Типичная схема работы:

```text
1. Разрешить TXINTR.
2. Записать первое слово вручную.
3. В обработчике добирать FIFO до порога.
4. Когда буфер исчерпан — запретить TXINTR.
```
