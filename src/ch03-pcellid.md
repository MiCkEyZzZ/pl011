# 3.3.16. Идентификация PrimeCell UARTPCellID0-3

Четыре 8-битных регистра в диапазоне `0xFF0`–`0xFFC` образуют
стандартный идентификатор PrimeCell, общий для всех компонентов
этого семейства.

## Расположение

| Регистр | Смещение | Значение |
|---------|----------|----------|
| `UARTPCellID0` | `0xFF0` | `0x0D` |
| `UARTPCellID1` | `0xFF4` | `0xF0` |
| `UARTPCellID2` | `0xFF8` | `0x05` |
| `UARTPCellID3` | `0xFFC` | `0xB1` |

Составное 32-битное значение — `0xB105F00D`.

## Назначение

Идентификатор `0xB105F00D` закреплён за семейством PrimeCell. Он
позволяет программному обеспечению отличить компоненты PrimeCell
от периферии других производителей.

В отличие от `UARTPeriphID0-3`, которые указывают на конкретный
компонент (PL011), регистры `UARTPCellID0-3` указывают на семейство
в целом.

## Битовые поля

| Регистр | Биты | Значение |
|---------|------|----------|
| `UARTPCellID0` | `[7:0]` | `0x0D` |
| `UARTPCellID1` | `[7:0]` | `0xF0` |
| `UARTPCellID2` | `[7:0]` | `0x05` |
| `UARTPCellID3` | `[7:0]` | `0xB1` |

Биты `[15:8]` каждого регистра зарезервированы: читаются неопределённо
и должны считаться нулями.

## Пример проверки

```c
static uint8_t pcell_byte(int i)
{
    return *(volatile uint32_t *)(UART_BASE + 0xFF0 + 4 * i) & 0xFF;
}

static int is_primecell(void)
{
    return pcell_byte(0) == 0x0D &&
           pcell_byte(1) == 0xF0 &&
           pcell_byte(2) == 0x05 &&
           pcell_byte(3) == 0xB1;
}
```

## Полная идентификация устройства

Правильная проверка включает оба набора регистров:

```text
1. UARTPCellID0-3 == 0xB105F00D  → это компонент PrimeCell
2. UARTPeriphID0-3 == 0x00141011 → это UART PL011
```

Первая проверка отсекает периферию других семейств, вторая — другие
компоненты PrimeCell.

## Замечание

Регистры только для чтения, запись игнорируется. Как и в случае
`UARTPeriphID`, при чтении нужно маскировать младший байт: старшие
биты 32-битного слова не определены. Все обращения — 32-битные.
