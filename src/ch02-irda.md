# 2.3. Функциональное описание IrDA SIR ENDEC

Блок IrDA SIR ENDEC (encoder/decoder) преобразует обычный последовательный
поток UART в инфракрасный сигнал и обратно. Он состоит из двух
независимых частей: передающего кодера и принимающего декодера.

## Зачем нужно кодирование

В электрической линии UART логическая единица — это высокий уровень,
логический ноль — низкий. Инфракрасный передатчик может только включаться
и выключаться, причём постоянно включённый свет расходует энергию
и мешает другим приёмникам.

Решение IrDA SIR: единица передаётся отсутствием света, а ноль —
коротким импульсом. Так средняя мощность излучения остаётся низкой,
а приёмник легко отличает импульс от фона.

## Структура

```text
                 ┌──────────────────────────────────────┐
   из передающей │  ┌──────────────┐                    │
   логики ───────┼─▶│   Кодер SIR  │──▶ nSIROUT ────────┼──▶ к драйверу ИК
                 │  └──────────────┘                    │
                 │                                      │
                 │  ┌──────────────┐                    │
   от фотоприём- │  │  Декодер SIR │◀── SIRIN ◀─────────┼── от фотоприёмника
   ника ─────────┼─▶│              │──▶ в принимающую   │
                 │  └──────────────┘    логику           │
                 └──────────────────────────────────────┘
```

## Управление

| Бит | Имя | Действие |
|-----|-----|----------|
| `UARTCR[1]` | `SIREN` | Включает блок SIR |
| `UARTCR[2]` | `SIRLP` | Выбирает режим низкого потребления |
| `UARTILPR[7:0]` | `ILPDVSR` | Задаёт делитель для `IrLPBaud16` |

Блок SIR работает только при включённом UART (`UARTEN = 1`).

## Сигналы

| Сигнал | Направление | Назначение |
|--------|-------------|------------|
| `nSIROUT` | выход | Импульсный выход к инфракрасному светодиоду (активен низким) |
| `SIRIN` | вход | Вход от фотоприёмника |

## Дуплекс

Обычный режим SIR — полудуплекс: в каждый момент устройство либо
передаёт, либо принимает. Контроллер не управляет переключением
направления автоматически; это задача программного обеспечения
или внешней схемы.

## Режим петли

При `LBE = 1`, `SIREN = 1` и `SIRTEST = 1` (бит 2 тестового регистра
`UARTTCR`) путь `nSIROUT` инвертируется и замыкается на `SIRIN`. Это
позволяет проверить кодер и декодер без внешнего фотоприёмника.
После окончания теста бит `SIRTEST` нужно сбросить.
