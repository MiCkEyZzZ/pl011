# 2.1. Обзор

Контроллер PL011 состоит из набора функциональных блоков, которые
преобразуют параллельные данные шины APB в последовательный поток
и обратно. Упрощённая структура показана на рисунке.

## Состав блоков

| Блок | Назначение |
|------|------------|
| Интерфейс AMBA APB | Приём и выполнение операций чтения и записи |
| Блок регистров | Хранение программно-доступных регистров |
| Генератор скорости | Формирование сигналов `Baud16` и `IrLPBaud16` из `UARTCLK` |
| Передающий FIFO | Буфер передаваемых символов, 16 записей |
| Принимающий FIFO | Буфер принятых символов с признаками ошибок, 16 записей |
| Передающая логика | Сдвиг битов, вставка стартового, стоповых битов и чётности |
| Принимающая логика | Выделение битов, проверка кадра и чётности, обнаружение ошибок |
| Логика прерываний | Формирование шести линий прерываний |
| Интерфейс DMA | Запросы к контроллеру DMA на передачу и приём |
| Синхронизация модемных входов | Устранение метастабильности асинхронных входов |
| Блок IrDA SIR | Кодирование и декодирование инфракрасного сигнала |
| Тестовые регистры и логика | Интеграционная тестовая обвязка |

## Два потока данных

**Передача.** Процессор записывает символ в `UARTDR`. Символ попадает
в передающий FIFO. Передающая логика извлекает его, добавляет стартовый бит,
биты данных, при необходимости бит чётности и стоп-биты, после чего выдаёт
результат на линию `TXD` с частотой, заданной генератором скорости.

**Приём.** Принимающая логика следит за линией `RXD`, обнаруживает
стартовый бит, выбирает биты данных по середине каждого битового интервала
и складывает символ вместе с признаками ошибок в принимающий FIFO.
Процессор читает `UARTDR` и получает очередной символ.
