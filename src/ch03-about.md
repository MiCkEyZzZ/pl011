# 3.1. Общие сведения

Базовый адрес контроллера не фиксирован: он назначается при интеграции
и может различаться в разных системах. Смещения всех регистров
относительно базового адреса постоянны.

## Правила доступа

- Все обращения выполняются 32-битными словами, выровненными
  по границе слова.
- Адрес регистра: `адрес = base + offset`.
- Регистры `RO` доступны только для чтения, запись игнорируется.
- Регистры `WO` доступны только для записи, чтение не имеет смысла.
- Зарезервированные поля нельзя изменять (DNM); при записи в регистр
  они должны сохранять прочитанное значение.
- Неиспользуемые биты читаются как нули, если не указано иное.

## Зарезервированные области

Во время нормальной работы обращаться к перечисленным адресам нельзя.

| Смещения | Назначение |
|----------|------------|
| `0x008`–`0x014`, `0x01C` | Зарезервировано |
| `0x04C`–`0x07C` | Резерв для будущих расширений |
| `0x080`–`0x08C` | Тестовые регистры (глава 4) |
| `0x090`–`0xFCC` | Резерв для будущих тестовых регистров |
| `0xFD0`–`0xFDC` | Резерв для будущих регистров идентификации |
| `0xFE0`–`0xFFC` | Регистры идентификации |

## Особенность UARTDR

`UARTDR` — не обычная ячейка памяти. Запись помещает символ в передающий
FIFO, чтение извлекает символ из принимающего FIFO. Поэтому два
обращения подряд с одним адресом могут дать разные результаты.

## Соглашение об именах

| Суффикс | Значение |
|---------|----------|
| `DR` | Data Register — регистр данных |
| `RSR` | Receive Status Register — статус приёма |
| `ECR` | Error Clear Register — сброс ошибок |
| `FR` | Flag Register — регистр флагов |
| `ILPR` | IrDA Low-Power counter Register |
| `IBRD` | Integer Baud Rate Divisor |
| `FBRD` | Fractional Baud Rate Divisor |
| `LCR_H` | Line Control Register (high half) |
| `CR` | Control Register |
| `IFLS` | Interrupt FIFO Level Select |
| `IMSC` | Interrupt Mask Set/Clear |
| `RIS` | Raw Interrupt Status |
| `MIS` | Masked Interrupt Status |
| `ICR` | Interrupt Clear Register |
| `DMACR` | DMA Control Register |

Суффикс `_H` в `UARTLCR_H` означает «верхняя половина»: исторически
существовал 30-битный регистр `UARTLCR`, и `UARTLCR_H` соответствует
его старшим битам.
