# 4.4.1. UARTTCR

`UARTTCR` — регистр управления тестом. Он задаёт режим работы
контроллера при проверке.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x080` |
| Тип | RW |
| Ширина | 3 бита |
| Значение после сброса | `0x0` |

## Битовые поля

| Бит | Имя | Описание |
|-----|-----|----------|
| 15:3 | — | Зарезервировано, при чтении не определено |
| 2 | `SIRTEST` | Разрешение теста SIR |
| 1 | `TESTFIFO` | Разрешение тестового FIFO |
| 0 | `ITEN` | Разрешение интеграционного теста |

## ITEN — интеграционный тест

При `ITEN = 1` контроллер переходит в режим интеграционного теста.
Внутрикристальные входы и выходы начинают управляться регистрами
`UARTITIP` и `UARTITOP` напрямую, вместо обычных сигналов.

При `ITEN = 0` действует обычный режим: входы берутся с выводов,
выходы формируются логикой UART.

## TESTFIFO — тестовый FIFO

При `TESTFIFO = 1`:

- запись в `UARTTDR` попадает в **принимающий** FIFO;
- чтение из `UARTTDR` извлекает данные из **передающего** FIFO.

Это позволяет проверить FIFO в обход обычного последовательного
тракта. При `TESTFIFO = 0` такой доступ запрещён. Значение после
сброса — 0.

## SIRTEST — тест SIR

При `SIRTEST = 1` разрешается работа приёмного тракта во время
передачи IrDA. Это нужно для теста в режиме полного дуплекса.

Бит должен быть установлен в 1, если требуется проверить SIR
в режиме шлейфа при включённом `LBE` (бит 7 `UARTCR`). При
`SIRTEST = 0` приёмная логика отключается на время передачи SIR,
что соответствует обычной полудуплексной работе.

## Пример

```c
#define UART_TCR   (UART_BASE + 0x080)

/* Включить интеграционный тест */
*(volatile uint32_t *)UART_TCR = 1u;

/* Включить обход FIFO */
*(volatile uint32_t *)UART_TCR = 2u;

/* Вернуться в обычный режим */
*(volatile uint32_t *)UART_TCR = 0u;
```
