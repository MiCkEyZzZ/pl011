# 4.5.2. Первичные входы

Первичные входы — это сигналы, приходящие на выводы кристалла.
Они проверяются с помощью внешней ловушки (trickbox), которая
соединяет выходы обратно со входами.

## Схема шлейфа

| Выход | Соединяется со входом |
|-------|-----------------------|
| `UARTTXD` | `UARTRXD` |
| `nSIROUT` | `SIRIN` |
| `nUARTRTS` | `nUARTCTS` |
| `nUARTOUT1` | `nUARTDCD` |
| `nUARTDTR` | `nUARTDSR` |
| `nUARTOUT2` | `nUARTRI` |

## Порядок проверки

```text
1. Записать 1 в ITEN (UARTTCR[0]).
2. Через биты UARTITOP[5:0] подать на выходы последовательность
   единиц и нулей.
3. Прочитать те же значения через биты UARTITIP[5:0].
4. Сравнить поданное и прочитанное.
```

## Соответствие битов

| Бит `UARTITOP` | Выход | Бит `UARTITIP` | Вход |
|----------------|-------|----------------|------|
| 0 | `UARTTXD` | 0 | `UARTRXD` |
| 1 | `nSIROUT` | 1 | `SIRIN` |
| 3 | `nUARTRTS` | 3 | `nUARTCTS` |
| 4 | `nUARTOUT1` | 4 | `nUARTDCD` |
| 2 | `nUARTDTR` | 2 | `nUARTDSR` |
| 5 | `nUARTOUT2` | 5 | `nUARTRI` |

## Особенности

- Все модемные линии активны низким уровнем. При подаче логической 1
  на выход `nUARTRTS` на входе `nUARTCTS` также будет 1, то есть
  линия в неактивном состоянии.
- Шлейф должен быть установлен внешне. Внутри кристалла такой связи
  нет.
- Проверять нужно оба значения — 0 и 1: иначе залипание на одном
  уровне останется незамеченным.

## Что проверяется

Такой тест подтверждает:

1. Выходной каскад формирует сигнал.
2. Вывод кристалла исправен.
3. Входной каскад принимает сигнал.
4. Внутренние линии `UARTITOP` и `UARTITIP` правильно связаны
   с выводами.
